## 何を作ったか

`サービスページ改善内容.xlsx` の与件どおりのセクション構成で、`/ad-lp/` を全面的に作り直しました。
トンマナは指定どおり https://lnx.co.jp/ と同一で、**共通CSS `assets/css/styles.css` をそのまま読み込み**、
LP固有の分だけ `ad-lp/style.css` に書いています（violet→blue のグラデーション、Inter+Noto Sans JP、角丸・影のトークンは共通変数を使用）。

構成: ヒーロー → 悩み → 解決の提示 → 選ばれる理由×3 → **成果事例（横スクロール5件）** → 中間CTA → サービス内容 → ご支援の流れ → 料金 → FAQ×8 → 関連コラム×6 → 問い合わせフォーム。
CTAは **FV / 中間 / 最終 / スマホ固定バー** の4か所すべて `#cta` に着地します。

  - 「日本一」「No.1」「必ず」「絶対」「100%」等の最上級・断定表現は**不使用**。

## 副次的に直したこと（このページ限定のCSS上書き）

作業中に、**共通CSSの既存の不具合**を2つ見つけたので、`ad-lp/style.css` 内でこのページだけ打ち消しています。

1. **`html,body{height:100%}` と `html,body{overflow-x:hidden}` が両方効いていて、`<body>` 自身がスクロールコンテナになっていた**
   → その結果 `position:sticky` のヘッダーが固定されず、`#アンカー` へのスクロールもずれます。
   このページでは `html,body{height:auto; min-height:100%}` で通常フローに戻しました。
   **同じ問題は他のページ（TOP等）でも起きているはずです。** 共通CSS側で直す場合は `styles.css:37` の `height:100%` を見直してください。
2. **フッターロゴが横に引き伸ばされていた** — `.t-footer__logo` に `height:34px` しか無く、幅が親いっぱいに広がる状態。
   `width:34px; object-fit:contain` を足しています。こちらも共通CSS側に反映すると全ページで直ります。

いずれも**共通CSSファイルは一切書き換えていません**（`ad-lp/style.css` 内での上書きのみ）。
