この表から読み取れるのは、リール中心のプランは1回あたりの単価が高くなる傾向があることです。動画の撮影・編集の手間が価格に表れていると考えられます。特にマジカルのリールプランは撮影を基本的に同社で行う前提のため、素材支給が基本のアルパカSNSとは「1本」に含まれる作業がまったく違います。また、アルパカSNSは税別、マジカルは税込の表記です。ただし、1回あたりの安さは、成果の大きさを意味しません。同じ「1回」でも、素材を自社が用意するのか、構成や原稿まで作ってもらうのかで価値が変わります。ほかの3社は月の投稿数を公開していないため、この比較には入れられませんでした。見積もりを取るときは、必ず「月に何を何本つくるか」を書面で出してもらい、同じ表に直して比べてください。

依頼の流れと、事前に決めておくこと

一般的な流れは、①問い合わせ・ヒアリング、②提案・見積もり、③契約、④アカウント設計・初期設定（アルパカSNSのように準備期間が約40営業日と書かれている会社もあります）、⑤運用開始、⑥月次レポートと改善、です。開始までに時間がかかる会社があるため、イベントや新商品の発売に合わせたい場合は、開始時期を最初に確認してください。

問い合わせの前に社内で決めておくと話が早いのは、次の4点です。

  1. 目的と指標：フォロワー数ではなく、予約・来店・応募・問い合わせなど事業側の指標。
  2. 素材の調達：撮影は誰が行うか。素材は支給が基本の会社が多いため、社内で用意できる量を把握する。
  3. 月の予算の上限と期間：最低契約期間ぶんの総額で考える。
  4. 社内の確認フロー：投稿前の承認を誰が、何営業日以内に行うか。

依頼前に確認する7項目

比較表で3社程度に絞れたら、問い合わせで次の7項目を同じ順で聞いてください。答えの具体性で差がつきます。

  1. 投稿の種類と本数：フィード・リール・ストーリーズを月に何本つくるか。ストーリーズは含まれるか。
  2. 素材と原稿：撮影は誰が行うか。構成案やキャプションの原稿づくりは月額に含まれるか。
  3. 担当者：提案する人と、毎月運用する人が同じか。担当者の経験した業種。
  4. アカウントの権限：自社名義で開設するか。管理者権限とログイン情報を契約終了後も自社が持てるか。
  5. 最低契約期間と解約条件：途中解約の可否、違約金、自動更新の扱い。
  6. レポート：どの数値を、いつ、どんな形式で報告するか。改善案まで含まれるか。
  7. 権利と費用の別建て：制作物の二次利用の範囲、撮影費・広告費・初期費用が別かどうか。

契約条件の解釈や、制作物の権利関係の個別の判断は、弁護士等の専門家に確認してください。契約後に思うような結果が出ないときの見直し方はSNS運用代行に依頼しても成果が出ない原因と立て直し方｜契約前後で見直す6つの論点が参考になります。

Instagram運用代行を選ぶとき、「何本つくってくれるか」と同じくらい「何のためのアカウントか」を見てほしいと考えています。フォロワー数やリーチは目安になりますが、予約・来店・応募・問い合わせにつながらなければ事業には効きません。そのため当社では、アカウント設計の段階で、誰に何を届けて何を行動のゴールにするかを先に決めます。

当社自身の取り組みとして、自社で運営する東京のデートグルメInstagramアカウントがあります。ターゲットを絞った投稿設計と分析を重ね、現在はフォロワー2.1万人、月間リーチ約150万に育っています。これは自社運営のアカウントの数値であり、お客様の運用成果を保証するものではありません。

依頼先を決めた時点がゴールではありません。毎月のレポートを見て、何を残し何をやめるかを一緒に決め続けられる相手かどうかが、半年後の差になります。見積もりを取るときは、金額の前に「最初の3か月で何を検証するのか」を聞いてみてください。答えが具体的であるほど、運用が始まってからのズレは小さくなります。当社の支援範囲は、事業内容ページに記載している内容が前提です。

よくある質問

Q Instagram運用代行の費用は、どのくらいを見込めばよいですか？

公式ページで月額を公開している会社の範囲では、月5万円〜（アルパカSNS・税別）、月5.8万円〜（マジカルのフィードプラン・税込）、月10万円〜（SAKIYOMIの運用代行）、月額15万円〜（当社の目安）と幅があり、リール動画を撮影から任せるプランでは月46万円（マジカル・税込）のものもあります。違いは、投稿の本数、制作の範囲、戦略設計や分析の有無です。金額だけでなく「月に何を何本つくるか」を揃えて、複数社に同じ条件で見積もりを依頼してください。

Q 契約期間はどのくらいが一般的ですか？

公式ページで確認できた範囲では、最低4か月（アルパカSNS）、最低6か月（マジカル。エンタープライズは12か月）、基本は3か月単位（当社）と大きく分かれます。契約期間を公開していない会社も多いため、問い合わせの段階で最低契約期間と解約条件を確認し、最低期間ぶんの総額で比較してください。

Q フォロワー数が増えれば成果が出たと考えてよいですか？

フォロワー数は目安の一つですが、予約・来店・応募・問い合わせなど事業側の指標とは別物です。契約前に、何を成果とするかを決め、その指標を月次レポートで報告してもらえるかを確認してください。

Q 契約が終わったとき、アカウントや投稿素材は自社に残りますか？

会社と契約内容によります。アカウントを自社名義で開設して管理者権限を自社が持つこと、制作物の二次利用の範囲、過去の数値やレポートの受け取り方を契約前に書面で確認してください。権利関係の個別の判断は弁護士等の専門家に確認することをおすすめします。

Q 素材（写真・動画）は自社で用意する必要がありますか？

会社によります。今回確認した範囲では、アルパカSNSは素材を顧客側が用意するのが基本と書かれています。マジカルは、リールの撮影は基本的に同社で対応し、フィードプランでは写真素材の提供を求める場合があるとしています。撮影まで依頼できるかは会社やプランで変わるため、撮影が月額に含まれるのか、別料金なのかを見積もり時に確認してください。

Q 複数社に見積もりを依頼するとき、何をそろえて伝えればよいですか？

運用したい目的と指標、現在のアカウントの状況、月に使える予算の上限、社内で用意できる素材の量、確認フローを、同じ文面で各社に伝えてください。条件をそろえると、提案の具体性と見積もりの内訳を同じ基準で比べられます。
