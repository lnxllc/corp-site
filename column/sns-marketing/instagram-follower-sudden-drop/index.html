「昨日まで1,000人いたフォロワーが、一晩で何十人も減っていた」「アプリの不具合ではないか」。企業や店舗のInstagramアカウントを運用していると、フォロワー数の急な減少に驚くことがあります。ただ、フォロワーの減少には、悪いものと、むしろアカウントの実態に近づいただけの良性のものがあります。この記事では、減り方の形から原因を絞り込む手順と、それぞれの対処を整理します。

結論：数字だけで慌てず、減り方の形を見る

結論1：一度に数人〜十数人が減る程度なら、スパム・偽アカウントの整理や、相手の退会・利用停止であることが多く、対処は不要な場合があります。
結論2：特定の日や、特定の投稿・キャンペーンの後に集中して減った場合は、投稿内容や企画設計が原因の可能性があります。
結論3：フォロワーだけでなく、リーチや保存数も同時に落ちているなら、アカウント全体の発信に問題があります。
結論4：不具合かどうかは、数日おいて推移を見てから判断します。すぐに投稿内容や設定をいじりません。
結論5：「誰が外したか分かる」とうたう外部ツールには、ログイン情報を渡さないでください。

そもそも、フォロワー数は事業の成果そのものではありません。数字が減った理由が実態に近づいた結果であれば、むしろ健全です。まず「減り方の形」を見ます。

最初に確かめる：いつ・何人・どんな形で減ったか

プロアカウント（ビジネス・クリエイター）なら、インサイトでフォロワーの増減を日別に確認できます。まず次の3点を押さえます。

  • いつ減ったか：特定の1日に集中しているのか、毎日少しずつ減っているのか。
  • 何人減ったか：全体の何パーセントか。数人なのか、数十人なのか、数百人なのか。
  • その前後に何があったか：投稿、ストーリーズ、広告配信、プレゼント企画、運用担当の交代など。
減り方の形考えられる状況最初の対応
特定の日に数人〜十数人が減るスパム・偽アカウントの整理、退会、利用停止数日様子を見る。リーチ・保存数に変化がなければ対処不要
毎日少しずつ、数週間続く発信内容のずれ、投稿頻度の変化、宣伝色の強まり直近の投稿を見直し、フォロワーの関心とずれていないか確認する
プレゼント企画やキャンペーンの終了直後に大きく減る景品目当てのフォロワーの離脱企画の設計を見直す。数字を落ち着いて受け止める
一度に数百人以上、または全体の1割以上が減るアカウントの制限・乗っ取り・外部連携の問題ログイン履歴とアカウントのステータスを確認する
フォロワーとリーチが同時に落ちるアカウント全体の質の問題投稿の質、頻度、内容を見直す

フォロワーが急に減る原因を5つに分ける

実務で見る原因は、次の5つに分けると整理しやすくなります。

1. 相手の退会・利用停止・アカウント削除

フォロワーが一時的にアカウントの利用を停止した場合は、再開すればフォロワーとして戻りますが、完全に削除した場合は戻りません。（出典：Instagramのフォロワーが減る原因と対処法｜TaTap）自社の運用では制御できない減少です。

2. スパム・偽アカウントの整理

解説記事によれば、スパムや偽アカウントが削除されると、それをフォロワーに持っていたアカウントの数字は自動的に減ります。（出典：Instagramのフォロワーが減る原因と対処法｜TaTap）企業アカウントにとっては、数字が実態に近づく良性の変化です。フォロワー数だけを目標にしていると、ここで不安になります。

3. 相手が自分でフォローを外した

投稿頻度の急な変化、内容のずれ、宣伝の増加が、主な理由として挙げられています。（出典：Instagramのフォロワーが減る原因と対処法｜TaTap）自社で直せるのは、この種類の減少です。

4. キャンペーン目的のフォロワーの離脱

プレゼント企画や割引目当てで増えたフォロワーは、企画終了後に離れやすいです。（出典：Instagramのフォロワーが減る原因と対処法｜TaTap）数が戻らないことを前提に、企画の目的を「数」から「見込み客の質」へ置き直す必要があります。

5. ブロック・アカウントの制限・不具合

特定の相手にブロックされた場合は、フォロワー数が1人減ります。また、Instagram側の一時的な表示の遅れや不具合の可能性もあります。ただし、不具合かどうかを自社だけで断定するのは難しいため、数日おいて推移を見たうえで判断します。

ポイント：1〜2は自社で対処できません。3〜4は発信内容の見直しで改善できます。5は様子を見て、必要なら設定を確認します。原因の種類によって、やるべきことがまったく違うのが、この問題の厄介な点です。

自分で原因を絞り込む手順

  1. インサイトで、フォロワーの増減を日別に確認する：減った日と人数を特定します。
  2. 減った日の前後の投稿・ストーリーズ・広告を見る：宣伝色が強い投稿や、普段と違う内容がなかったかを確認します。
  3. リーチ・保存数・プロフィールへのアクセスの推移を重ねる：フォロワーだけが減っているなら、アカウント側の要因が疑われます。同時に落ちていれば、投稿の質の問題です。
  4. 直近4週間と、その前の4週間を比べる：一時的な変動か、傾向的な減少かを見分けます。
  5. 特定の相手が気になるなら、その人のプロフィールを開いて確認する：外したことを通知する機能はありません。
  6. ログイン履歴と連携アプリを確認する：身に覚えのないログインや、外部ツールの連携が残っていないかを確認します。

確認チェックリスト

  • 減った日と人数をインサイトで特定したか
  • 減った日の前後の投稿・企画・広告を確認したか
  • リーチ・保存数が同時に落ちていないか
  • 直近4週間と、その前の4週間を比べたか
  • 身に覚えのないログインや連携アプリがないか
  • 二段階認証を有効にしているか
  • 「誰が外したか分かる」外部ツールを使っていないか

注意：「誰がフォローを外したか分かる」とうたう外部ツールにログイン情報を渡すと、アカウントの乗っ取りにつながるおそれがあります。{SRC}確認が必要なら、インサイトと相手のプロフィールだけで行います。

原因別の対処と、やってはいけないこと

原因対処やってはいけないこと
スパム・偽アカウントの整理、退会対処不要。フォロワー数ではなく、リーチ・保存数・プロフィールへのアクセスを見る数字を戻すためにフォロワーを買う、相互フォローを募る
発信内容のずれ・宣伝の増加直近の投稿を見直し、役立つ投稿と宣伝投稿の比率を整える焦って投稿頻度を急に増やす・減らす
キャンペーン後の離脱企画の目的を見直し、見込み客が参加したくなる景品・条件に設計し直す毎回、景品の価値だけを上げて数を集める
ブロック・制限が疑われるアカウントのステータスを確認し、指摘があれば是正する新しいアカウントを作って回避する
乗っ取り・連携の問題パスワード変更、二段階認証の有効化、不要な連携の解除外部の「確認ツール」にログイン情報を渡す

LnXの見解

フォロワーの急な減少の相談を受けたとき、最初にお伝えするのは「数字が減ったこと自体は、必ずしも悪いことではない」という点です。スパムや偽アカウントの整理で数字が実態に近づくのは健全ですし、プレゼント企画で集めたフォロワーが離れるのも自然な動きです。

一方で、フォロワーとリーチが同時に落ちているなら、発信そのものに課題があります。見るべきはフォロワー数ではなく、リーチ・保存数・プロフィールへのアクセス、そして問い合わせや来店といった事業の結果です。数字に一喜一憂して投稿を急に変えるのが、最も避けたい対応です。

運用の指標設計や、アカウントの立て直しを相談したい場合は、お気軽にご連絡ください。LnXでは、フォロワー数に頼らない運用の設計からご支援しています。

よくある質問

Q フォロワーが急に減ったのは、Instagramの不具合でしょうか？

不具合の可能性もありますが、自社だけでは断定できません。スパムや偽アカウントの整理、相手の退会など、通常の動きで減ることも多くあります。数日おいて推移を見て、リーチや保存数に変化がなければ様子を見て問題ありません。

Q 誰がフォローを外したか分かるツールは使ってよいですか？

おすすめしません。ログイン情報を渡すと、アカウントの乗っ取りにつながるおそれがあります。確認したい相手がいる場合は、その人のプロフィールを開いて、フォローの状態を見る方法が安全です。

Q フォロワーを買って数を戻してもよいですか？

避けてください。反応しないアカウントが増えると、投稿への反応率が下がり、実態の分かりにくい数字になります。数を戻すより、リーチ・保存数・問い合わせといった事業の結果を見る方向に切り替えるのが得策です。

Q プレゼント企画のあとで大きく減りました。失敗でしょうか？

景品目当てのフォロワーは、企画終了後に離れやすく、一定の減少は想定内です。企画の目的が「数」だったのか「見込み客」だったのかを振り返り、次回は参加条件や景品を、自社のサービスに関心のある人が集まる設計に変えます。

Q 一度に大きく減った場合、まず何を確認すべきですか？

ログイン履歴に身に覚えのないアクセスがないか、連携している外部アプリがないか、アカウントに制限の通知が出ていないかを確認します。二段階認証が有効でなければ、すぐに設定してください。
