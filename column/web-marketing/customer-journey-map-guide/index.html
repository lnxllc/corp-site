カスタマージャーニーとは？ペルソナ・ファネルとの違い

カスタマージャーニーは、見込み客があなたの会社を知ってから、買う（契約する）まで、さらに使い続けるまでの道のりを、時間の流れに沿って整理したものです。そこに「何を考え、何に迷い、どこで離れるか」を書き込んだ1枚の図表が、カスタマージャーニーマップです。

似た言葉との違いを整理しておくと、作る目的がぶれません。

用語答えること単体での限界
ペルソナ誰に届けるのか（顧客像）その人が「いつ・何に迷うか」までは分からない
ファネル（認知→検討→購入）どの段階で何人が減っているか（人数の流れ）減った理由と、そのときの気持ちは分からない
カスタマージャーニー各段階で何を考え、何を見て、なぜ進むか・止まるか実データで検証しないと、作り手の想像になりやすい

つまりカスタマージャーニーは、ペルソナとファネルをつないで「どこに、どんな施策を置くべきか」を決めるための道具です。広告・SEO・SNS・LP・営業がバラバラに動いている会社ほど、全体を1枚で見るだけで優先順位が見えやすくなります。

作り始める前に決める3つ：対象・ゴール・範囲

カスタマージャーニーが「きれいな図は完成したが、何も変わらなかった」で終わる原因の大半は、作る前の設計にあります。次の3つを先に決めてください。

  1. 対象の顧客を1タイプに絞る：「中小企業の経営者全般」ではなく、「従業員20名前後で、初めて広告を外注しようとしている社長」のように、行動が想像できる粒度で1タイプに。複数タイプを同じ図に入れると、どの矢印も曖昧になります。
  2. ゴールを数字で決める：問い合わせ、資料請求、来店予約、購入、継続契約のどれを「到達点」にするか。1つに決めます。
  3. 描く範囲を決める：最初から「認知から継続まで」を全部描かず、まず最も人数が減っている区間（例：サイトを見たのに問い合わせが来ない）から始めます。

この3つは、KPIツリーの作り方｜施策につなげる手順で整理するKPIの考え方とつながっています。ゴールの数字が決まっていれば、ジャーニーのどの区間を直すと数字が動くかを逆算できます。

カスタマージャーニーの作り方：5ステップ

ステップ1：段階を3〜5つに区切る

中小企業なら、細かく分けすぎないのがコツです。目安は「気づく」「比べる」「決める」の3段階、継続や紹介まで見るなら「使う」「広げる」を加えた5段階です。専門用語（認知・興味・比較・購入…）にこだわらず、社内で通じる言葉で区切ってください。

ステップ2：各段階の「行動」を書く

見込み客が実際に取る行動を書きます。たとえば「比べる」段階なら、「検索で3〜4社のサイトを開く」「口コミを見る」「知人に聞く」「見積もりを2社に依頼する」などです。自社のサイトに来る前後の行動まで書くのがポイントです。

ステップ3：接点（タッチポイント）を洗い出す

行動の中で、自社と触れる場所を列挙します。検索結果、広告、SNS、サイト、LP、メール、電話、営業との面談、見積書などです。自社が管理できていない接点（口コミサイト、知人の紹介）も、その存在だけは書いておきます。

ステップ4：「考え」「不安」「離れる理由」を書く

最も価値が出る部分です。各段階で、見込み客が何を考え、何に不安を持ち、どんなときに離れるのかを書きます。ここは想像で書かず、次の章で説明する実データや現場の声を根拠にします。

ステップ5：改善の打ち手と担当・指標を決める

離れる理由が見えたら、それを解消する打ち手を1つずつ書き、担当者と見る指標を決めます。打ち手を書かないジャーニーは、現状の整理で終わってしまいます。

1枚に入れる項目：中小企業向けの最小テンプレート

項目を増やしすぎると、更新されない図になります。最初は次の6行で十分です。

項目書くこと書き方のコツ
段階気づく／比べる／決める（＋使う）社内で通じる言葉にする
行動見込み客が実際にすること「検索する」ではなく「何と検索するか」まで
接点自社と触れる場所管理できない接点にも印をつける
考え・不安迷い、疑問、気になる点お客様の言葉のまま書く
離れる理由次に進まない原因根拠のないものは「仮説」と明記する
打ち手・指標解消する施策と、見る数字1区間につき打ち手は1〜2個

仮説と事実を分けて書く：データや発言の裏づけがある項目と、社内の想像で書いた項目を、色や記号で区別しておきます。想像の部分は、後で検証すべき「仮説」として扱えるので、図が更新される資料になります。

記入例：地方の税理士事務所が「比べる」段階を直す（仮の例）

以下は、考え方を示すための架空の例です。実在の事務所や数値ではありません。

項目「気づく」「比べる」「決める」
行動「地域名＋税理士 顧問料」で検索する3事務所のサイトを開き、料金と対応業種を見比べる無料相談の予約をする／見積もりを依頼する
接点検索結果、地図の口コミサイトの料金ページ、サービスページ予約フォーム、電話、初回面談
考え・不安顧問料の相場が分からない自分の業種に詳しいか分からない相談したら断れなくなるのでは
離れる理由料金の目安が見つからない対応業種の実例が載っていない初回相談の内容と費用が不明
打ち手・指標料金の目安を記事化（検索流入）業種別の対応例ページを追加（料金ページの次の遷移率）「初回相談は無料・契約の義務なし」を明記（予約率）

この例では、「比べる」段階で離れる理由が「対応業種の実例がない」と分かったため、最優先の打ち手がブログ記事や広告ではなくサイトの1ページの追加になっています。ジャーニーを描く価値は、「新しい施策を足す」のではなく、「いま足りない1か所」を特定できることにあります。

想像を根拠に変える：社内にあるデータの集め先

「考え・不安」「離れる理由」を埋める材料は、新しく調査をしなくても社内にあります。

集め先分かること集め方の例
問い合わせ・商談の記録相談時に最初に聞かれること、最終的な決め手直近10〜20件の質問を書き出す
失注・見送りの理由比較で負けた理由、不安だった点営業担当に「見送りの理由」を一言ずつ聞く
既存のお客様への聞き取り選んだ理由、他社と比べた点契約直後に3問だけ聞く
アクセス解析（GA4など）どのページで離れているか、どの経路から来たか入口ページと、問い合わせ前に見られるページを確認
検索キーワード・サイト内検索見込み客が使う言葉Search Consoleのクエリ、サイト内検索の語
口コミ・SNS評価の理由、不満の理由自社と競合の口コミを読み比べる

とくに効果が大きいのは「失注の理由」と「問い合わせ時の最初の質問」です。この2つを10〜20件並べるだけで、「比べる」段階の不安がほぼ見えてきます。数字はあくまで自社のデータであり、他社の数字を当てはめるものではありません。

施策への落とし込み：チャネル・指標・優先度の決め方

離れる理由が出そろったら、打ち手を次の3点で整理します。

  1. どの区間か：人数が最も減っている区間（またはゴールに最も近い区間）を優先する。
  2. どのチャネルで直すか：サイト改修で済むのか、広告・SEO・SNSなど集客施策が必要なのか。接点が自社サイトなら、改修のほうが早く効くことが多い。
  3. 何で効果を見るか：区間ごとに1つの指標を決める（例：料金ページからの遷移率、予約率）。

優先順位は、「効果の大きさ」「手間の軽さ」「根拠の強さ」の3軸で付けると決めやすくなります。詳しい考え方はマーケティング施策の優先順位の決め方で、予算の配分は広告・SEO・SNSの予算配分の決め方｜チャネル別の役割と比率の目安で整理しています。

よくある失敗5つ

  1. 作り手の想像だけで描く：「お客様はこう考えるはず」で埋めた図は、現場の感覚とずれます。根拠のある項目と仮説を分けてください。
  2. 最初から全段階を描く：範囲が広すぎて、どの打ち手が重要か分からなくなります。最も人数が減る区間から。
  3. 顧客タイプを混ぜる：新規客と既存客、個人と法人を同じ図に入れると、矢印が増えて使えなくなります。
  4. 打ち手と指標を書かない：現状の整理で終わり、実行されません。担当者と見る数字までを1枚に入れます。
  5. 作って終わりにする：半年に1回は、実データで見直します。更新の日付を図に書いておくと、古い図が使われ続けるのを防げます。

LnXの見解

カスタマージャーニーは、きれいに描くことが目的ではなく、「いま、どこに手を打つべきか」を決めるための道具だと考えています。広告、SNS、LP、サイトがそれぞれ別の担当や外注先で動いていると、各施策の数字は良く見えても、お客様の道のり全体では穴があいたままになりがちです。

当社のマーケティング顧問では、事業目標とKPIを整理したうえで施策を選び、実行を管理し、改善する流れで支援しています。ジャーニーの整理はその入口の一つです。ただし、顧問料に含まれるのは戦略立案・数値分析・改善提案・施策設計・ディレクションなどで、広告運用の実作業やLP・Web制作、バナー・動画の制作などの実務は別途のお見積もりになります。「何から手をつけるか」の整理だけで足りるのか、実行まで必要なのかを、無料相談で切り分けてお伝えします。

図を一人で描いて抱え込むより、問い合わせの記録や失注の理由を持ち寄って、第三者と一緒に10〜20件を並べてみるだけでも、次の一手は見えてきます。

よくある質問

Q カスタマージャーニーマップは、何を使って作ればよいですか？

表計算ソフトやスライドの表で十分です。専用ツールを導入する必要はありません。最初は「段階」「行動」「接点」「考え・不安」「離れる理由」「打ち手・指標」の6行を埋める1枚から始めてください。

Q ペルソナは先に作っておく必要がありますか？

詳細なペルソナ資料は必須ではありません。ただし「誰のジャーニーか」を1タイプに絞る必要はあります。年齢や職業の細かい設定より、「何に困って、どんな基準で比べるか」が書ければ十分です。

Q お客様へのインタビューができない場合はどうすればよいですか？

問い合わせ・商談の記録、失注の理由、アクセス解析、口コミなど、社内にあるデータから始められます。想像で埋めた部分は「仮説」と明記し、あとから検証してください。

Q BtoBとBtoCで、作り方は変わりますか？

基本の5ステップは同じです。BtoBは検討に関わる人が複数いて、期間も長くなるため、「担当者」「決裁者」のように役割ごとに分けるか、まず窓口となる担当者のジャーニーに絞るのが現実的です。

Q どのくらいの頻度で見直すべきですか？

半年に1回、または大きな施策を入れた後が目安です。サイトの改修や価格の変更、競合の動きがあったときは、該当する区間だけを更新してください。

Q 作ったジャーニーを、社外の制作会社や広告会社に渡してもよいですか？

渡すと、施策の目的が共有しやすくなります。ただし、顧客の個人情報や社内の失注情報が含まれる場合は、渡す範囲と取り扱いを事前に決めてください。個別の契約や情報管理の判断は、弁護士等の専門家に確認することをおすすめします。
