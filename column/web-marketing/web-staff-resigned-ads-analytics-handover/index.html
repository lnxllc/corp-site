Web担当者が退職したときの
広告・計測の引き継ぎ手順

2026年11月9日 引き継ぎ広告運用計測

この記事でわかること

  • 担当者が辞めたあと、最初の2週間で「やること」と「まだ触らないこと」の分け方
  • Google広告・GA4で、先に確認すべき権限と、管理者を1人にしない理由
  • 支払い・契約・計測の「止まると困る」ものの棚卸し表
  • 自社で回すか、外部に頼むかを決める判断の目安

結論：担当者が退職したら、最初の2週間は「改善」ではなく「守る」ことに集中します。順番は、①ログインできる人と権限の確認、②広告費の支払いと契約の確認、③計測が動いているかの確認、④直近の数字の保存、の4つです。広告の設定変更やアカウントの作り直しは、ここが済むまで行いません。権限の確認は、前任者のアカウントを消す前に行うのが鉄則です。

目次

最初に決める：守るものと、まだ触らないもの

担当者が急にいなくなると、「何から分からないのか」が分からない状態になります。そこで焦って広告の設定を直したり、サイトを触ったりすると、状況を悪くすることがあります。最初に、次の2つを分けます。

区分内容理由
最初の2週間で守るものログイン権限、広告費の支払い、契約中のツール・外注先、計測、直近の数字これが止まると、広告が止まる・数字が消える・追加費用が出る
まだ触らないもの運用中の広告の大幅な変更、アカウントの作り直し、サイトの作り替え何が成果につながっているか分からない状態での変更は、原因の特定を難しくする

ここでの考え方は、「改善」の前に「現状の可視化」を置く、ということです。前任者がいれば聞けたはずの情報を、残された画面や記録から復元する作業と言い換えられます。

手順① 権限：ログインできる人を確認する

最優先は、広告アカウントとアクセス解析に、いま誰がどの権限で入れるかの確認です。ここで見落としやすいのが、「管理者が前任者1人だけ」というケースです。

Google広告の場合

公式ヘルプでは、アクセス権は「メール専用」「お支払いとご請求」「読み取り専用」「標準」「管理者」に分かれています。このうち、アクセス権の付与・変更や、他のユーザーが送った招待の取り消し、Googleアナリティクスとのリンク設定ができるのは管理者です。また、管理者が1人だけだと、その人が対応できなくなったときにタグへアクセスできなくなる可能性があるため、管理者を少なくとも1人追加すると安心だと案内されています。（出典：Google 広告アカウントのアクセス権の種類について｜Google 広告 ヘルプ）

  • 広告アカウントの「アクセスとセキュリティ」で、ユーザー一覧と各自の権限を確認する
  • 管理者が前任者だけなら、前任者が退職する前に、会社のメールアドレスの管理者を追加してもらう
  • MCC（管理アカウント）が所有者に設定されていないかも確認する。設定されている場合、その管理者がお客様アカウントの権限を編集できる

GA4（Googleアナリティクス）の場合

公式ヘルプでは、GA4の管理者は、ユーザーの追加・削除や役割・データ制限の割り当てを含め、アナリティクスのすべてを管理できる役割です。役割は、アカウント単位とプロパティ単位で付けられ、親のアカウントで付けた役割は、デフォルトで配下のすべてのプロパティに継承されます。（出典：アクセス権とデータ制限の管理｜アナリティクス ヘルプ）

  • 「管理」からアカウントとプロパティのアクセス管理を開き、管理者の役割を持つ人を確認する
  • 管理者が前任者の個人のメールアドレスだけなら、会社のメールアドレスの管理者を追加する
  • GTM（タグマネージャー）、Search Console、サイトのサーバー・ドメインの管理画面も、同じ観点で確認する

順番が大事：前任者のアカウントを無効にする、削除する、といった操作は、新しい管理者がログインできることを確かめてからにします。先に消すと、誰も権限を付けられなくなるおそれがあります。なお、退職者のアカウントの扱いは社内規程によるため、不明な点は社内の情報システム担当や社労士に確認してください。

手順② 支払いと契約：止まる前に押さえる

権限の次は、お金の流れです。広告は、支払いが止まれば配信も止まります。確認するのは次の3つです。

  • 広告費の支払い方法：誰のクレジットカード、どの口座で支払っているか。前任者の個人カードや個人名義の可能性もあります。カードの有効期限が近いものがないかも確認します
  • 請求の管理者：Google広告のお支払いプロファイルのユーザーは、広告アカウント側から直接、追加・削除・変更できず、連絡先担当者などからサポートへの依頼が必要です（出典：Google 広告アカウントのアクセス権の種類について｜Google 広告 ヘルプ）。時間がかかることがあるため、早めに確認します
  • 契約中のツール・外注先：ホームページの保守、ドメイン・サーバー、MA・CRM、アクセス解析ツール、制作会社、代理店。契約者・更新日・解約条件を一覧にします

契約や請求は、請求書・メール・クレジットカードの明細から逆算すると、前任者の資料がなくても、おおむね復元できます。経理の担当者に「ここ1年の、広告・ツール・サーバー関連の支払い」を一覧にしてもらうのが近道です。

手順③ 計測：動いているかを確認する

担当者が辞めたあとに、気づかれないまま止まりやすいのが計測です。タグを入れた人がいなくなると、サイトを改修したときに計測が壊れても、誰も気づけません。確認は次の順で行います。

  1. GA4のリアルタイムで、自分の訪問が表示されるか：自分でサイトを開き、反映を確かめます
  2. コンバージョン（問い合わせ・購入）が、直近で記録されているか：実際の問い合わせ数と、管理画面の数を見比べます
  3. 広告管理画面のコンバージョンのステータス：「設定が不適切」と出ていないかを確認します。見方はGoogle広告のCVが待機中・設定が不適切の直し方を参照してください
  4. タグの入れ方の把握：GTMで入れているのか、サイトに直接貼っているのか。誰がいつ変更したかは、GTMのバージョン履歴で追えます

計測が止まっているのに、広告だけが動いている状態を放置すると、「成果が出ているのかどうか」を判断できないまま広告費だけが出ていきます。月1回の点検の考え方はGA4の計測が止まっていても気づけない？月1回の計測監査と異常検知の仕組みの作り方で整理しています。

手順④ 直近の数字を保存する

前任者がいなくなると、「それまでの数字の見方」も一緒に失われます。いまのうちに、次の数字を保存しておきます。

  • 広告：直近3〜6か月の月別の広告費・クリック数・コンバージョン数・獲得単価（キャンペーン別）
  • サイト：月別のセッション数・問い合わせ数・流入元の内訳
  • 営業側：問い合わせから商談・受注までの件数（CRMや営業の記録）
  • 前任者が作っていたレポート、スプレッドシート、ダッシュボードの場所とURL

数字は、表の形で残すのが最も確実です。画面のスクリーンショットだけでは、後から比較できません。「あとで見返す」ではなく、退職の前後で、最初に保存しておきます。

引き継ぎ棚卸し表

ここまでの確認を、1枚の表にまとめます。これが、新しい担当者や外部の支援会社に渡す、最小限の引き継ぎ資料になります。

項目確認する場所書き出す内容
広告アカウント各媒体の管理画面（Google広告・Metaなど）アカウントID、管理者、支払い方法、請求の管理者
アクセス解析GA4、Search Console、GTM管理者、タグの入れ方、コンバージョンの定義
サイトドメイン、サーバー、CMSの管理画面契約者、更新日、ログイン権限、保守の委託先
契約ツール・外注先請求書、カード明細、経理への確認サービス名、月額、契約者、更新日、解約条件
数字・レポート前任者の共有フォルダ、スプレッドシート保存場所、更新方法、直近の実績
運用中の施策広告の管理画面、SNS、メール配信いま動いているもの、止めると困るもの

この表で「分からない」が残った項目が、そのまま、外部に相談する論点になります。

そのあと：自社で回すか、外部に頼むか

2週間で守るべきものを押さえたら、次は「誰が運用するか」を決めます。選択肢は大きく4つです。

選択肢向いている状況気をつけること
後任を社内で決める広告・計測の経験がある人が社内にいる兼任の場合、時間が足りなくなりやすい
新しく採用する長期的に内製したい採用に時間がかかり、その間の空白が長くなる
運用を外部に任せる実務を早く回したい権限を渡す範囲と、契約の条件を決めておく
判断役だけ外部に頼む実務の担当はいるが、優先順位を決める人がいない実務の作業が別に必要かを確認する

4つの比較はマーケ顧問・CMO代行・業務委託・採用の4択比較、責任者を採用するか外注するかの費用面はマーケティング責任者は採用か外注か｜費用と比較、担当が1人しかいない体制の作り方はマーケティング担当1人の会社の体制と外注の分け方で整理しています。

判断の目安（当社の考え方）：棚卸し表で「分からない」が多く、社内に確認できる人がいない場合は、実務を任せる前に、まず現状の整理と判断を外部に頼むほうが、結果的に手戻りが少なくなります。広告アカウントの引き継ぎについては広告アカウントの所有権｜引き継ぎ手順と失う資産も参照してください。

LnXの見解

担当者の退職で困る会社の多くは、前任者の能力の問題ではなく、広告・計測・契約の情報が、1人の頭と1つのアカウントに集中していたことが原因です。退職は、それが表に出るきっかけにすぎません。だからこそ、辞めた後に慌てて直すより、棚卸し表を作って、管理者を複数にしておくことが、最も安く済む対策です。

LnXのマーケティング顧問制度は、代表が直接、現状の整理から施策の優先順位づけ、改善提案までを支援します。料金は、アドバイザリープランが月8万円（月1回の定例）、グロース伴走プランが月15万円（月2回の定例）、マーケティング責任者プランが月30万円で、最低契約期間は原則3か月、価格は税別想定です（LPの記載による）。広告運用の実作業やLP・Web制作などの実務は、別途お見積りとなります。担当者がいなくなって、何から手をつけるか決められない段階でも、無料相談で課題の整理から始められます。

よくある質問

Q担当者が退職する前に、最低限やっておくことは何ですか？

広告アカウントとGA4・GTMの管理者に、会社のメールアドレスのユーザーを追加してもらうことです。公式ヘルプでも、管理者が1人だけだと、その人が対応できなくなったときにタグへアクセスできなくなる可能性があるため、管理者を少なくとも1人追加することが案内されています。次に、広告費の支払い方法と、契約中のツールの一覧を作ってもらいます。

Qすでに退職してしまい、前任者と連絡がつきません。どうすればよいですか？

まず、会社のメールアドレスや、すでに持っているアカウントで入れる範囲を確認します。管理者権限を持つ人がいない場合は、各サービスの所有者の確認手順に沿って対応します。ドメインやサーバーの契約者は、請求書やカード明細から特定できることが多いため、経理に確認してください。

Q前任者のアカウントは、すぐに削除してよいですか？

新しい管理者がログインできることを確認してからにしてください。先に削除すると、権限を付け直せなくなるおそれがあります。退職者のアカウントの扱いは社内規程にもよるため、情報システム担当や社労士にも確認してください。

Q引き継ぎ資料がなくても、広告の運用は続けられますか？

運用中の設定を変えずに、数字を見守ることは可能です。ただし、何が成果につながっているかが分からない状態での大きな変更は避けてください。まず直近の数字を保存し、棚卸し表で現状を整理してから、変更の優先順位を決めます。

Q外部に頼むなら、最初に何を依頼すればよいですか？

実務の運用を任せる前に、現状の整理と、何を優先するかの判断を依頼すると手戻りが少なくなります。棚卸し表で「分からない」が残った項目を、そのまま相談の論点として渡すと、話が早く進みます。
