ペルソナとは？ターゲットとの違いと、作っても使われない理由

ペルソナは、自社の商品やサービスを買ってくれる人を、実在の一人のように具体的に描いたものです。「30代女性・会社員」のように属性で括るターゲットに対して、ペルソナは「何がきっかけで探し始め、何を比べ、何が不安で、誰の了承が要ったのか」まで書きます。広告の見出しやLPの構成、営業トークを考えるときに「この人なら何と言われたら動くか」を判断する物差しになります。

ただ、中小企業ではペルソナを作ったのに誰も使っていないという状況がよく起こります。理由はたいてい次の3つです。想像で埋めたので現場の実感と合わない、年齢・性別・趣味といった「プロフィール」だけで購買の判断材料がない、そして作った目的が決まっていないので、どの施策にも結びつかない。この記事では、この3つを避けるために「直近の受注客5社」から作る方法を、そのまま使える1枚シートと記入例つきで説明します。顧客の動きをさらに時系列で整理したい場合は、カスタマージャーニーの作り方｜中小企業向け手順と例が続きになります。

作る前に決める3つ：用途・範囲・材料

最初に手を動かす前に、次の3つを決めておくと、あとで迷いません。

  1. 用途：何の判断に使うのかを一つ決めます。広告の見出しを作る、LPの構成を決める、営業トークを揃える、コラムのテーマを選ぶ、のうちまず一つです。用途が決まると、書く項目も決まります。
  2. 範囲：1つの商品、1つの購入場面に絞ります。「全商品の全顧客」を一人にまとめると、誰にも当てはまらない像になります。
  3. 材料：社内にある実際のデータを使います。受注客の一覧、問い合わせの履歴、営業メモ、失注の理由、広告の検索語句などです。材料が少ない場合も、想像で埋めずに「分からない」と書いておきます。

ペルソナの数は、最初は1〜2つで十分です。数を増やすほど管理が重くなり、使われなくなります。

受注客5社から作る5ステップ

ここからが本題です。ネットで見かける作り方は、ペルソナの項目を埋めるところから入るものが多いのですが、当社は「実際に買ってくれた5社」から逆算するほうが、中小企業では外れにくいと考えています。理由は、人数が少ないので一社ごとの顔が見えること、購買の事実があるので想像が入りにくいことです。

1

直近の受注客を5社選ぶ

受注時期が新しい順に、「また付き合いたい」と思える5社を選びます。単価が低く手間ばかりかかった客は、別の機会に分析します。顧客数が少ない会社は3社でも始められます。

2

6つの質問で、購入までの経緯を書き出す

営業メモやメール、担当者の記憶から、5社それぞれについて次の6つを書きます。分からないところは空欄で構いません。

  • きっかけ：何があって探し始めたか（担当者の退職、売上の頭打ち、他社への不満など）
  • 最初に探した言葉：検索したのか、紹介を頼ったのか
  • 比較した相手：他に検討した会社や、内製という選択肢
  • 決め手：最終的に選んだ理由
  • 不安だったこと：契約前にためらった点
  • 決めた人：担当者一人か、上司や社長の了承が必要だったか
3

共通点と違いを分ける

5社を並べて、全社に共通することと社ごとに違うことに分けます。共通点がペルソナの中心になり、違いは「亜種」としてメモしておきます。3社以上で同じことが出てきたら、共通点として扱います。

4

1枚のシートにまとめる

次の節の8項目で、A4一枚にまとめます。名前と顔写真は、チームで呼び合うための仮のものです。

5

3つの場面で使い、ずれを直す

広告の見出し、LPの冒頭、営業の最初の質問の3か所で実際に使います。反応が合わない場面があれば、ステップ2に戻って経緯を足します。

5社の共通点が見つからないときの直し方

5社を並べても共通点が出てこないことがあります。これは失敗ではなく、「顧客が複数のタイプに分かれている」というサインです。無理に平均を取って一人にまとめず、次の3つの切り口で分け直してみてください。

  1. きっかけ別：「担当者の退職」「売上の頭打ち」「社長の指示」など、探し始めた出来事でグループに分けます。きっかけが同じなら、探す言葉も不安も似てくることが多いです。
  2. 決める人別：担当者が一人で決めた客と、社長の了承が要った客では、必要な資料が違います。
  3. 受注額・継続別：長く付き合ってくれている客だけで作り直します。単発で終わった客と混ぜると、像がぼやけます。

分けた結果、一番人数の多いグループを最初のペルソナにします。残りのグループは「亜種」として、項目2（きっかけ）と項目7（決める人）の違いだけをメモしておけば十分です。最初から3人分を完成させる必要はありません。

1枚シートの8項目と、記入例

シートに書くのは、次の8項目です。年齢・性別・趣味は、購買の判断に関わるときだけ書きます。判断材料にならない属性を並べても、施策には使えません。

項目書くこと元にする材料
1. 誰か（役割）業種、会社規模、本人の役職と担当範囲受注客の一覧、名刺
2. きっかけ探し始めた出来事営業メモ、初回の問い合わせ文面
3. 最初に探す言葉検索語句、紹介元、相談先問い合わせフォームの回答、Search Consoleの検索語句
4. 比較する相手競合、内製、「何もしない」商談での質問、失注の理由
5. 決め手選んだ理由を本人の言葉で受注後のヒアリング、お礼のメール
6. 不安契約前にためらった点商談で出た質問、見積もり後の問い合わせ
7. 決める人と、了承が必要な人担当者と決裁者の関係商談の同席者、稟議の有無
8. 響く言葉・響かない言葉刺さった表現と、避けたい表現成約した提案書、広告の反応

次は記入例です。以下は説明のために作った架空の例であり、実在の会社や調査結果ではありません。「社員10名のオフィス内装会社」が、受注客5社から作ったという想定です。

項目記入例（架空・仮置き）
1. 誰か従業員20〜50名の会社の総務担当（兼任）。オフィスの増床か移転を任された
2. きっかけ社員が増えて手狭になった。社長から「今期中に何とかして」と言われた
3. 最初に探す言葉「オフィス 内装 費用」「オフィス 移転 内装 流れ」。知人の紹介を頼る人もいる
4. 比較する相手大手の内装会社、知人の工務店、「今のレイアウトのまま我慢する」
5. 決め手見積もりの内訳が細かかったこと。「総務の自分でも社長に説明できた」
6. 不安予算が超えないか、工事中の業務への影響、担当者が忙しくて確認が遅れること
7. 決める人担当者が候補を絞り、社長が最終決定。社長への説明資料が要る
8. 響く言葉「社長への説明資料を作ります」「工事中の動線を事前に確認します」。「理想のオフィス」「おしゃれ」は響かなかった

この例で注目してほしいのは、購入者本人の不安（社長に説明できるか）が、そのまま打ち手になることです。広告の見出しなら「社長への説明資料つき」、LPなら「見積もりの内訳の見本」、営業なら最初の質問を「社長にはどう説明する予定ですか」にできます。年齢や趣味を書いても、ここまでの具体策は出てきません。

材料が少ないときの集め方

受注客が5社に満たない、記録が残っていない場合は、次の順で材料を集めます。

  1. 営業・受注の担当者に15分ずつ聞く：6つの質問を、記録ではなく記憶から答えてもらいます。「なぜ選ばれたと思うか」を聞くのが一番早いです。
  2. 問い合わせフォームの内容を読む：自由記述の文面には、お客様の言葉がそのまま出ています。
  3. 検索の入り口を確認する：Search Consoleの検索語句や、広告の検索語句レポートから、最初に探されている言葉を拾います。
  4. 受注客に短く聞く：メールで3問程度。「なぜ当社に問い合わせたか」「他に検討した会社は」「不安だったことは」だけで十分です。

お客様への聞き取りや記録の保管では、個人情報の取り扱いに注意が必要です。録音・記録の同意の取り方や保管の方法など、個別の判断は自社の規程に従い、必要に応じて弁護士等の専門家に確認してください。

BtoBでは「一人」ではなく「役割」で書く

BtoBの購入では、担当者、決裁者、実際に使う部門など、複数の人が関わるのが普通です。他社の解説でも、担当者だけでなく関係者の情報ニーズを設定することが注意点として挙げられています。ペルソナを無理に一人にまとめず、先ほどの項目7を使って「担当者」「決裁者」の2役に分けて書くのが現実的です。

役割知りたいこと響く情報の例
担当者（比較・調査をする人）何ができるか、費用の目安、進め方、他社との違い料金表、事例、流れの図、比較表
決裁者（最終決定をする人）投資に見合うか、失敗したときのリスク、他に選択肢はないか費用対効果の考え方、契約期間と解約条件、実績
利用部門（実際に使う人）現場の手間が増えないか、使いこなせるか導入後の運用の流れ、サポート体制

担当者向けと決裁者向けでは、同じ商品でも見せる順番と言葉が変わります。担当者が社内に説明するための資料を、こちらから用意しておけると、商談は進みやすくなります。

作ったペルソナを、4つの場面で使う

ペルソナは作って終わりではなく、使う場面を先に決めておくと生きます。

場面使い方確認すること
広告の見出し項目2（きっかけ）と項目6（不安）をそのまま見出しにクリック率が上がったか。想定と違う語句で検索されていないか
LP・サービスページ項目5（決め手）を冒頭に置く。項目6の不安への答えを中盤に置く問い合わせ率の変化、フォームで入力が止まる項目
営業トーク最初の質問を項目2・7から作る初回商談から2回目に進む割合
コラム・ブログ項目3（探す言葉）と項目4（比較）から記事テーマを選ぶ検索流入、記事から問い合わせに進んだ数

用途ごとに見るべき数字は違いますが、最初は1つの場面だけで十分です。たとえば広告の見出しを2案作って比べるだけでも、ペルソナが合っていたかを確かめられます。

ペルソナづくりで失敗しやすい5つのパターン

  1. プロフィールを並べるだけ：年齢・年収・家族構成・趣味を書いて満足し、購買の経緯が空白。
  2. 理想の顧客を描いてしまう：「こういう客に来てほしい」が混ざり、実際の受注客と離れる。
  3. 数を作りすぎる：5人も10人も作り、結局どれも使われない。
  4. 社内の一人で作る：営業や受注の現場の話が入らない。最低でも営業と制作の担当者の2人で作る。
  5. 作って放置する：半年経っても更新されない。新規の受注が増えたら、シートの共通点を見直す。

見直しの目安として、当社が実務で見ているのは四半期に1回、新しい受注客の経緯を2〜3社分だけ足す運用です。大がかりにやり直す必要はなく、共通点が崩れていないかを確かめるだけで十分です。

LnXの見解

ペルソナづくりでは、見た目の整った1枚を作ることより、実際の受注客の経緯から「次に何を変えるか」が決まることのほうが大切だと考えています。ペルソナが広告にもLPにも営業にも反映されて初めて、作った意味が出ます。

当社のマーケティング顧問制度は、事業目標の整理、KPI設計、施策選定、実行管理、改善という流れで、施策の優先順位づけを支援するものです。ペルソナの整理もその一部として扱えますが、顧問料の範囲は戦略立案・数値分析・改善提案・施策設計・ディレクションなどで、広告運用の実作業やLP・Web制作、バナー・動画制作などの実務は別途お見積もりとなります。まずはこの記事の5ステップを、社内で一度試してみてください。そのうえで「共通点が見つからない」「施策に落とせない」場合は、無料相談で現状の課題を一緒に整理できます。

よくある質問

Q ペルソナは何人作ればよいですか？

最初は1〜2人で十分です。数を増やすほど管理が重くなり、使われなくなります。BtoBで決裁者が別にいる場合は、一人にまとめず「担当者」と「決裁者」の2役に分けて書く方法もあります。

Q ペルソナとターゲットは何が違いますか？

ターゲットは「30代の会社員」のように属性で括った対象で、ペルソナは購入までの経緯（きっかけ・比較・決め手・不安）まで具体的に描いた一人の人物像です。ターゲットで範囲を決め、ペルソナでその中身を具体化すると使いやすくなります。

Q 受注客が少なくて、5社も集まりません。

3社でも始められます。それも難しい場合は、営業担当者に「なぜ選ばれたと思うか」を聞くところから始め、問い合わせフォームの文面や検索の語句を材料に仮のペルソナを作り、新しい受注のたびに更新してください。

Q ペルソナはどのくらいの頻度で見直しますか？

当社が実務で見ている目安は、四半期に1回、新しい受注客2〜3社分の経緯を足して、共通点が崩れていないかを確かめる程度です。商品や価格を大きく変えたときは、早めに見直してください。

Q ネットの調査データや統計は使わなくてよいですか？

中小企業では、自社の受注客の経緯のほうが判断に直結します。外部の統計は、市場の大きさや傾向を知る補助として使い、ペルソナ本体は自社データで作るのがおすすめです。

Q 顧客へのヒアリングや記録で注意することはありますか？

録音・記録は同意を得てから行い、氏名や連絡先などの個人情報の保管と利用目的を自社の規程に合わせて管理してください。法的な判断が必要な場合は、弁護士等の専門家に確認してください。
