工務店のホームページに
問い合わせが来ない原因と見直し手順

  • 30分でできる、最初に見る数字の確認手順
  • 施工事例・価格・問い合わせの段階など、関門ごとの直し方

結論：工務店のホームページに問い合わせが来ない原因は、「見つからない」「比べる材料がない」「問い合わせの一歩が重い」「問い合わせを数えられていない」の4つに分かれます。最初に、地域名で検索したときに自社が出るか、施工事例のページが読まれているかを数字で確かめてください。注文住宅は検討期間が長く、複数社を比べてから問い合わせる人がほとんどです。価格の目安と事例の中身が見えないと、見学会や資料請求の前に候補から外されます。原因が分かるまでは、デザインのリニューアルや広告の追加より、事例と導線の見直しを先にしてください。

原因は4つの関門で切り分ける

「ホームページを作ったのに、資料請求も見学会の予約も来ない」という悩みは、工務店や注文住宅会社からよく聞きます。ただ、問い合わせが来ない理由は一つではありません。家を建てたい人がホームページから問い合わせるまでには、次の4つの関門があり、どこで止まっているかで直す場所が変わります。

関門止まっている状態よくある原因
1. 見つからない「地域名＋工務店」「地域名＋注文住宅」で検索しても自社が出ないサイトが検索に登録されていない、Googleビジネスプロフィールが未整備、地域名がページにない
2. 比べる材料がないサイトには来ているが、施工事例や会社紹介で離れている価格の目安がない、事例が写真だけ、他社との違いが分からない
3. 一歩が重い比べたうえで、問い合わせの手前で止まっている入口が「お問い合わせ」だけ、フォームの項目が多い、スマホで押しにくい
4. 数えられていない実は問い合わせはあるが、数字として把握できていない電話・LINE・ポータル経由が別々に管理されている、計測が入っていない

手前の関門で止まっているのに、後ろの関門を直しても効果は出ません。たとえば検索で見つからないままフォームを改善しても、そもそもフォームを見る人がいません。上から順に、どこで止まっているかを確かめるのが近道です。

自分で確かめる：30分でできる数字の確認

感覚ではなく、数字で止まっている場所を探します。直近3か月の数字を、次の順に確認してください。

確認の手順

  • Googleで「site:自社のドメイン」と検索する：主なページが出てこない場合は、関門1の手前で止まっている
  • 「地域名＋工務店」「地域名＋注文住宅」で検索する：地図の枠と通常の検索結果の両方で、自社が何番目に出るかを記録する
  • Search Consoleで、表示回数とクリック数を見る：地域名を含むクエリで表示が出ているか、クリックされているかを確認する
  • Googleビジネスプロフィールのパフォーマンスを見る：プロフィールの閲覧数、ウェブサイトへのクリック、電話、ルート検索の数を控える
  • GA4で、施工事例ページと会社紹介ページの閲覧数を見る：トップページだけ見られて事例が見られていないなら、関門2で止まっている
  • 問い合わせフォームのページの閲覧数と、送信数を比べる：フォームは開かれているのに送信が少ないなら、関門3で止まっている
  • 電話・LINE・住宅ポータル経由の問い合わせを、同じ表に集める：合計すると実は問い合わせがある、という場合は関門4

Googleの公式SEOスターターガイドでも、サイトが検索に登録されているかは「site:」検索で確認できると案内されています（出典：Google 公式 SEO スターター ガイド｜Google 検索セントラル）。ここで主なページが出ない場合は、内容の改善より先に、技術的な問題がないかを制作会社に確認してください。

関門1：地域名で検索しても見つからない

工務店を探す人の多くは、「市区町村名＋工務店」「市区町村名＋注文住宅」「市区町村名＋平屋」のように、地域名を入れて検索します。ここで出てこなければ、比べてもらう機会もありません。

地図の枠：Googleビジネスプロフィールを整える

Googleは、ローカル検索結果の順位は主に「関連性」「距離」「知名度」の組み合わせで決まると説明しています。知名度には、クチコミの数や評価、ウェブ上の情報が影響するとされています（出典：Google のローカル検索結果のランキングを改善するヒント｜Google ビジネス プロフィール ヘルプ）。業種のカテゴリ、対応エリア、営業時間、施工写真を正確に埋め、お引き渡しをしたお客様にクチコミをお願いし、届いたクチコミに返信を続けることが基本です。整え方の全体像はMEO対策（Googleビジネスプロフィール）とは？店舗集客の始め方と広告・SNSとの使い分けで解説しています。

通常の検索結果：ページに地域名と家のタイプを書く

施工エリアがトップページの画像の中にしか書かれていない、事例に地域名がない、というサイトは少なくありません。施工エリアは本文の文字で書き、施工事例にも「◯◯市・平屋・延床30坪」のように地域と家のタイプを入れます。「◯◯市で平屋を建てる」のような、地域と悩みを組み合わせたページがあると、具体的な検索で見つかりやすくなります。

関門2：見つけても比べる材料がない

注文住宅は高額で、検討期間も長いため、ほとんどの人は複数社のサイトを見比べてから問い合わせます。そこで比べる材料が見つからないと、問い合わせる前に候補から外されます。当社が実務で見ている範囲では、問い合わせが少ない工務店のサイトに共通するのは、次の3つの不足です。

価格の目安が分からない

「価格はお問い合わせください」だけでは、予算に合うか分からず、問い合わせの心理的な負担が大きくなります。総額の幅（例：建物本体で◯◯万円〜◯◯万円が中心）と、その価格に何が含まれ、何が含まれないかを書いておくと、比較の土台に乗れます。含まれる範囲を書くことで、安さだけで比べられることも減ります。

施工事例が写真だけ

きれいな写真が並んでいても、どんな家族が、いくらで、何にこだわって建てたのかが分からないと、自分の家づくりに重ねられません。事例ごとに、価格帯・延床面積・工期・家族構成・こだわった点・お客様の声を入れます。件数を増やすより、1件の中身を厚くするほうが効果的です。

他社との違いが見えない

「自然素材」「高性能」「地域密着」は、多くの工務店が同じ言葉を使っています。断熱や耐震の考え方、標準仕様、アフターメンテナンスの中身、担当者が誰か、家づくりの流れと期間など、具体的な事実で違いを書くと、比べる人に伝わります。性能値を書くときは、どの基準での値かもあわせて明記してください。

関門3：問い合わせの一歩が重い

比べたうえで興味を持っても、「お問い合わせ」ボタン一つしかないと、まだ営業を受けたくない人は押しません。家づくりの検討段階に合わせて、軽い入口から重い入口まで段階を用意します。

検討の段階用意したい入口ポイント
情報を集めている資料請求・カタログのダウンロード入力項目は名前・連絡先・住所程度に絞る
候補を絞っている見学会・モデルハウスの予約、オンライン相談日程をフォームで選べるようにする。スマホで最後まで入力できるか確かめる
具体的に考えている個別相談・資金計画の相談・土地探しの相談相談で何が分かるか、営業の連絡の有無を書いておく

あわせて、スマホで見たときに、電話番号がタップでかけられるか、問い合わせボタンが画面の下に固定されているかも確認します。フォームの項目数や入力の負担を減らす方法はフォーム離脱を減らすには？入力率を上げるEFO改善方法｜チェックリスト付きで詳しく解説しています。

関門4：問い合わせを数えられていない

工務店の問い合わせは、フォームだけでなく、電話、LINE、住宅ポータル、紹介、見学会の当日来場など、入口がばらばらです。フォームの件数だけを見て「ホームページから問い合わせが来ない」と判断していると、実は電話で問い合わせが来ていた、ということがあります。

  • 問い合わせ台帳を一本化する：入口（フォーム・電話・LINE・ポータル・紹介）と、「何を見て知ったか」を必ず聞いて記録する
  • Webの計測を入れる：フォームの送信、電話番号のタップ、LINEボタンのクリックをGA4のキーイベントとして計測する
  • 来場と契約までつなげて見る：問い合わせの件数だけでなく、見学会の来場、商談、契約まで、どの入口から来た人が進んでいるかを見る

電話の計測方法は電話問い合わせの計測方法｜通話コンバージョン設定で解説しています。

直す順番と、外部に相談する目安

直す順番は、止まっている関門のうち、いちばん手前からです。手間と効果の出やすさで並べると、次のようになります。

  1. 問い合わせ台帳と計測を整える（関門4）：直した効果を測るための土台。1〜2週間で整えられる
  2. Googleビジネスプロフィールと施工エリアの記載（関門1）：費用をかけずにすぐ着手できる
  3. 施工事例と価格の目安を書き足す（関門2）：既存の事例の情報を足すところから始める
  4. 問い合わせの入口を段階的に増やす（関門3）：資料請求と見学会予約の入口を分ける

件数が月に数件と少ない場合は、問い合わせ数だけでなく、施工事例ページの閲覧数やフォームを開いた数など、手前の数字の変化で判断します。3か月単位で比べると、住宅展示場のイベント時期など季節の波も見分けやすくなります。

先にやらないほうがよいこと：原因が分かる前の全面リニューアルと、広告費の追加です。比べる材料がないサイトに広告で人を集めても、同じところで離れてしまいます。リニューアルで問い合わせが減るケースもあるため、進める場合はHPリニューアル後に問い合わせが減った原因の確認点も事前に押さえてください。

次のような場合は、社内だけで進めるより、外部の目を入れたほうが早いことがあります。

  • 4つの関門のどこで止まっているか、数字を見ても判断がつかない
  • ホームページ・Googleビジネスプロフィール・ポータル・広告を別々の会社に頼んでいて、全体を見ている人がいない
  • 施工事例の取材や更新を続ける人手がない

LnXの見解

工務店の集客の相談を受けると、ホームページそのものより、「比べる人が知りたいことに答えていない」ことが原因になっている場合が多いと感じます。施主は、価格の幅、建てた人の実例、担当者の顔、建てたあとの付き合い方を知りたがっています。どれも工務店の手元にすでにある情報で、新しく作るものではありません。まずはそれをサイトに出すことが、費用をかけずにできる一番の改善です。

一方で、検索・地図・ポータル・SNS・見学会と入口が多い業種だからこそ、どこに力を入れるかの判断が難しくなります。施策を一つずつ足す前に、数字で止まっている関門を決め、優先順位を付けることが大切です。社内にその判断をする人がいない場合は、戦略から一緒に組み立てる顧問の形で伴走することもできます。

よくある質問

Q施工事例は何件くらい載せればいいですか？

件数より、1件ごとの情報量を優先してください。価格帯・延床面積・工期・家族構成・こだわった点が書かれた事例が数件あるほうが、写真だけの事例が数十件あるより比較の材料になります。目安は、自社の主力の価格帯と間取りの事例が、それぞれ1件以上あることです。

Q価格を載せると、安さだけで比べられませんか？

価格を出さないと、問い合わせの前に候補から外されることがあります。総額の幅と、その価格に含まれるもの・含まれないものを書いておけば、安さだけの比較になりにくく、相談時の認識のずれも減ります。

Q住宅ポータルサイトに掲載しているので、ホームページは最低限でいいですか？

ポータルで知った人も、多くは会社名で検索して自社のホームページを確認します。ポータルに載っている情報と自社サイトの情報が食い違っていたり、自社サイトに事例が少なかったりすると、そこで比較から外れることがあります。

QGoogleビジネスプロフィールは何を整えればいいですか？

Googleは、ローカル検索の順位は関連性・距離・知名度の組み合わせで決まると説明しています。業種・対応エリア・営業時間・写真を正確に埋め、クチコミに返信を続けることが基本です。

Q問い合わせが月に数件しかないのですが、改善の効果は測れますか？

件数が少ない場合は、問い合わせ数だけで判断せず、施工事例ページの閲覧数、資料請求フォームを開いた数、電話のタップ数など、手前の数字の変化で判断します。3か月単位で比べると、季節の波の影響も見分けやすくなります。
