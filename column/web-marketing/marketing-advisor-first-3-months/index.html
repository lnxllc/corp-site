最初の3か月の全体像：何を決め、何が手元に残るのか

結論から言うと、マーケティング顧問の最初の3か月は、「1か月目で現状と優先順位を決め、2か月目で絞った施策を動かし、3か月目で続けるかどうかを数字で判断する」という流れで考えるのが現実的です。当社では最低契約期間を原則3か月としており、1か月目に現状分析と方針設計を行い、2か月目以降に実行と改善に入ります。

顧問契約は、結果が出る前に費用が先に発生します。だからこそ、各月の終わりに「何が手元に残っているか」を決めておくと、契約の価値を自分で判断できます。

期間主な目的月末に手元に残るもの社内の主な役割
1か月目現状分析と方針設計現状の数字の整理、課題の優先順位、実行する施策の候補数字と権限の共有、現場の事情の説明
2か月目絞った施策の実行1〜2本の施策の実行結果、最初の数値の動き施策の実行、顧問への状況共有
3か月目検証と次の判断施策ごとの継続・修正・停止の判断、次の3か月の計画継続するかどうかの意思決定

なお、3か月で売上が大きく動くとは限りません。事業や施策の性質によって結果が出るまでの期間は異なり、顧問料の金額で成果が保証されるものでもありません。3か月で見るべきなのは、判断の質が上がったか、止まっていた施策が動き出したかです。顧問の仕事の中身そのものは、マーケティング顧問は「戦略だけ」か「実行」もするのか？契約前に確認すべき業務範囲の境界線で整理しています。

契約前から初月までに、社内で用意しておくもの

1か月目の分析は、どれだけ早く正確な材料が揃うかで進み方が変わります。材料の提供が遅れると、1か月目が丸ごと「待ち」になってしまいます。契約の前後で、次の5点を揃えておくとスムーズです。

  1. 数字：直近6〜12か月の売上、問い合わせ数、成約数。チャネル別（広告・自然検索・SNS・紹介など）に分けられるとなお良い状態です。
  2. アカウントへの閲覧権限：Google Analytics、Search Console、広告アカウント、SNSの管理画面など。当社は原則としてお客様のアカウントを用い、権限をお預かりして作業します。
  3. 過去の施策と結果：やったこと、やめたこと、やめた理由。失敗した施策の情報は、同じ失敗を繰り返さないための重要な材料になります。
  4. 外注先の一覧：広告代理店、制作会社、フリーランスなどの担当範囲と契約内容。顧問が指示を出す相手を把握するためです。
  5. 意思決定者と決め方：誰が最終的に決めるのか、予算の承認にどれくらい時間がかかるのか。

すべて完璧に揃っている必要はありません。「数字が整理されていない」という状態を、そのまま見せてもらうことが、分析の出発点になります。担当者が不在の会社でも依頼できますが、その場合は初月の材料集めに顧問側が関わる時間が増えるため、事前に相談してください。相談前の整理はWebマーケティング会社に相談する前に整理すべきこと｜チェックリスト付きが使えます。

1か月目：現状分析と方針設計でやること

1か月目の目的は、施策を増やすことではなく、「何に手を打つか、何をやらないか」を数字から決めることです。進め方の一例を、週ごとに示します（当社が想定している進め方の例であり、事業や状況によって変わります）。

時期顧問側の作業社内に求めること
第1週ヒアリング、数字と権限の受け取り、過去施策の確認材料の提供、現場の事情の説明
第2週チャネル別・段階別の数字の整理、ボトルネックの仮説づくり仮説に対する現場の感覚の共有
第3週課題の優先順位づけ、実行する施策の候補を3〜5本に絞る予算と工数の上限の確認
第4週方針の提示、2か月目に動かす1〜2本の決定、KPIの設定方針への合意、実行担当者の決定

ここで大切なのは、KPIを「施策の数」ではなく「事業の数字から逆算した分解」で置くことです。たとえば成果を「人数×1人あたりの回数×成約率」のように分け、どこが一番弱いかを特定します。弱い箇所が分かれば、打つ手は自然に絞られます。

当社が顧問契約として行った事例ではありませんが、この考え方がよく表れた支援実績があります。保険代理店のインフルエンサー集客で、成果ゼロの状態から、成果を「人数×1人あたり訴求回数×訴求CVR」にKPI分解し、報酬体系の見直しと訴求テンプレートの整備に絞って再設計しました。

1か月目に「成果が出ていない」と焦らないこと。1か月目は分析と設計の期間なので、売上が動かないのは自然なことです。確認すべきなのは、月末に課題の優先順位と2か月目の施策が、数字の根拠つきで手元に残っているかどうかです。

2か月目：施策を1〜2本に絞って動かす

2か月目から実行と改善に入ります。ここで起きやすい失敗が、1か月目に出た候補を全部いっぺんに走らせてしまうことです。担当者の工数が足りず、どの施策が効いたのか分からなくなります。

顧問の契約範囲では、戦略立案・数値分析・改善提案・施策設計・ディレクションといった「判断と指示」が中心です。広告運用の実作業、LP・Web制作、バナーや動画の制作、SNS投稿の制作などの実務は、別途の見積もりか、別の担当者・外注先で進める形になるのが一般的です。2か月目で最初に決めるのは「誰が手を動かすか」です。

  1. 施策ごとに、実行担当を決める：社内の担当者か、既存の外注先か、新たに依頼する先か。
  2. 見る数字を1〜2個に絞る：施策の成否を判断する指標を、実行前に決めておく。
  3. 定例で結果を見る：定例は数字を見て翌月の動きを決める場であり、報告会にしない。
  4. 小さく直す：入力の不備や設定の軽微な修正は、その場で直して次の定例を待たない。

定例の進め方はマーケティングの月次定例は何を話すべきか｜数字の振り返りから翌月アクションを決める会議設計で詳しく書いています。

3か月目：検証して、継続・修正・卒業を決める

3か月目は、最初の契約期間の終わりに向けて、顧問を続けるかどうかを判断する月です。判断の材料は、売上の増減だけではありません。次の3つの問いで整理すると、感覚ではなく根拠で決められます。

問い見ること判断の目安
施策は動いたか2か月目に決めた施策が、実行され、数字が取れているか動いていなければ原因（工数・権限・判断の遅れ）を特定する
数字は、想定した方向に動いたか施策ごとの指標が、事前に決めた方向に向かっているか動いた施策は継続、動かない施策は修正か停止
顧問がいなくても、判断できる範囲は増えたか優先順位づけや外注先への指示を、社内でどこまでできるようになったか増えていれば、関与頻度を下げる選択肢がある

この結果から、次の3つの選択肢が見えてきます。同じ関与度で継続する、定例の頻度を上げて踏み込む、頻度を下げて社内に移していくです。成果の出ない施策をどこでやめるかは、成果の出ない施策はいつやめる？Webマーケティングの撤退基準と見直しサイクルの作り方の考え方が使えます。

数字が動いていない場合でも、すぐに「顧問は意味がない」と結論づけないでください。原因が、施策の中身にあるのか、実行体制にあるのか、材料の不足にあるのかで、次の手は変わります。この切り分けこそ、3か月目に顧問へ求めることです。

最初の定例で、顧問に聞いておきたい5つの質問

最初の定例は、これから3か月の「ものさし」を揃える場です。ここで次の5つを確認しておくと、途中での認識のズレを減らせます。

  1. 「今月の終わりに、何が手元に残りますか？」：月ごとの成果物を言葉にしてもらう。
  2. 「数字の定義を、いま揃えられますか？」：問い合わせ・成約・商談など、社内で数え方が違う指標を1つの定義に揃える。
  3. 「実作業は誰が担いますか？」：顧問料に含まれる範囲と、別見積もりになる範囲を一覧で確認する。
  4. 「連絡はどの手段で、どれくらいの速さですか？」：チャット相談の有無と、返信の目安を確認する。
  5. 「うまくいかなかったとき、どう見直しますか？」：3か月目を待たずに軌道修正する場の持ち方を決める。

顧問の稼働の実態については週1回・月2回の定例だけで成果は出る？マーケティング顧問の実際の稼働・関わり方で整理しています。質問に具体的に答えてもらえるかどうかは、顧問選びそのものの判断材料にもなります。

顧問・社内担当者・外注先の役割分担

最初の3か月が空回りする最大の原因は、誰が何をするのかが曖昧なまま走り出すことです。次の表を契約前に埋めておくと、役割のすれ違いを防げます。

役割顧問社内担当者外注先
優先順位の判断数字から案を出す現場の事情を伝える-
KPIの設定設計する合意する-
施策の実作業原則担わない（別見積もり）可能な範囲で担う制作・運用を担う
外注先への指示要件を整理して指示する窓口になる指示に沿って実行
結果の確認と改善案数値を分析して提案する変更を現場に落とす運用データを共有

広告費・制作費・ツール利用料などの実費は顧問料とは別に発生します。顧問料は、戦略策定・KPI管理・施策推進・改善実行に対する対価であり、成果や売上を保証するものではありません。

最初の3か月で「うまく進んでいない」5つのサイン

3か月目の判断を待たずに、途中で軌道修正すべき兆候もあります。次の5つに当てはまる場合は、顧問に率直に伝えて、進め方を見直してください。

  1. 定例が報告会になっている：数字の確認だけで終わり、翌月の動きが決まらない。
  2. 1か月目の分析が終わらない：材料や権限が揃わず、分析が先に進まない。
  3. 施策が増え続けている：絞るはずの施策が、毎月増えて現場が回らない。
  4. 実行担当が決まっていない：施策は決まったが、誰も手を動かしていない。
  5. 数字の定義が人によって違う：同じ「問い合わせ数」でも、部署ごとに数え方が違う。

どれも、顧問の力量だけでなく社内の体制や材料の問題であることが多く、早めに共有するほど立て直しやすくなります。失敗の型はマーケティング顧問導入でよくある失敗と契約前に確認すべき5つのことも参考にしてください。

顧問料は月額で示されることが多いため、最低契約期間をかけた総額で考えると判断しやすくなります。当社のプランで、顧問料だけを3か月分で計算すると次のとおりです（税別想定の単純計算です）。

ここに、顧問料とは別に発生するものを足して考える必要があります。広告費、LP・Web制作費、バナーや動画の制作費、SNS投稿の制作費、撮影費、ツールの利用料などです。2か月目に動かす施策が決まった時点で、実行にかかる費用の見積もりを取り、「顧問料＋実行費用」の総額が予算に収まるかを確認してください。

プランによって、最初の3か月の進み方はどう変わるか

当社の顧問制度は、関与度の違う3つのプランを用意しています（価格は税別想定、最低契約期間は原則3か月）。最初の3か月の進み方は、プランによって次のように変わります。

プラン月額定例の頻度最初の3か月の進み方
アドバイザリープラン8万円月1回数値・施策のレビューが中心。社内担当者が実行し、優先順位と翌月のアクションを整理する
グロース伴走プラン15万円月2回KPI・施策設計から制作物のレビュー、担当者への具体的な指示まで伴走する。月次の改善レポートつき

LnXの見解

顧問契約の最初の3か月で、いちばん避けたいのは、「何となく相談して、何となく続いている」状態です。顧問は、やることを増やす人ではなく、やることを絞る人です。そのため当社では、最初の1か月を分析と方針設計に使い、2か月目以降の施策を数字の根拠つきで絞り込んでから実行に入ります。

お客様側にお願いしたいのは、完璧な準備ではなく、「いま止まっている判断は何か」を率直に出してもらうことです。数字が整理されていなくても、担当者がいなくても構いません。そのままの状況から、一緒に整理を始められます。

3か月が終わった時点で、「顧問がいなくても判断できる範囲が増えた」のであれば、それも一つの成果だと考えています。関与度を上げるか、下げるか、卒業するかを、数字で一緒に決めましょう。他社の顧問や代理店の提案を並べた状態でのご相談も歓迎です。

よくある質問

Q マーケティング顧問の最初の3か月で、成果は出ますか？

事業や施策の性質によって異なり、3か月で売上が大きく動くとは限りません。顧問料の金額で成果が保証されるものでもありません。最初の3か月で確認するのは、課題の優先順位が数字の根拠つきで決まったか、止まっていた施策が動き出したか、継続・修正・停止の判断ができる状態になったかです。

Q 1か月目は、具体的に何をするのですか？

現状分析と方針設計を行います。数字と権限の受け取り、過去施策の確認、チャネル別・段階別の数字の整理、ボトルネックの仮説づくり、課題の優先順位づけ、2か月目に動かす施策の決定とKPIの設定が主な作業です。この期間は分析と設計が中心のため、売上が動くことは期待しない前提で進めます。

Q 社内にマーケティング担当者がいなくても依頼できますか？

可能です。担当者が不在の場合も、現状整理から実行ディレクションまで支援します。ただし、広告運用の実作業やLP・Web制作などの実務は顧問料に含まれないため、実行する先（社内の兼任者、外注先など）を決める必要があります。実務そのものが必要な場合は、外注先の提案も可能です。

Q 最低契約期間が3か月なのはなぜですか？

1か月目に現状分析と方針設計を行い、実行して数字が動き始めるのが2か月目以降になるためです。1〜2か月で解約すると、分析と設計だけで終わり、施策の結果を見ないまま判断することになります。期間の長さよりも、各月の終わりに何が手元に残るかを確認してください。

Q 3か月経ったあと、続けるかどうかはどう決めればよいですか？

施策が実行されたか、数字が想定した方向に動いたか、顧問がいなくても判断できる範囲が増えたかの3点で判断します。続ける場合も、同じ関与度で続ける、頻度を上げて踏み込む、頻度を下げて社内に移していくという選択肢があります。

Q 広告費や制作費は、顧問料に含まれますか？

含まれません。広告費・制作費・ツール利用料などの実費は別途発生します。顧問料は戦略策定・KPI管理・施策推進・改善実行に対する対価で、広告運用の実作業やLP・Web制作、バナーや動画の制作、SNS投稿の制作、撮影などの実務は別途お見積もりとなります。
