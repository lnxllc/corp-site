計測・GA4

Meta広告のリンククリックと
LPビューの差が大きい原因

2026年11月24日 Meta広告計測LP

この記事でわかること

  • Meta広告の「リンクのクリック」と「ランディングページビュー」が数えているものの違い
  • リンクのクリックに比べてランディングページビューが少なくなる、よくある原因6つ
  • 配置面・端末・ピクセルの3点から差の出どころを突き止める確認手順
  • 原因別の直し方と、どこまでの差なら様子を見てよいかの目安

結論：リンクのクリックとランディングページビュー（LPビュー）の差は、ある程度は必ず出ます。リンクのクリックは「広告のリンクが押された数」で、LPビューは「押した人のブラウザでLPが読み込まれ、Metaピクセルが反応した数」だからです。差が大きいときは、LPの表示が遅い・ピクセルがLPで動いていない・リンクのクリックにサイト以外の行き先が混ざっているのどれかを最初に疑います。どれに当たるかは、配置面別・端末別に分けて見て、広告のURLを実際にInstagramやFacebookのアプリ内で開くと短時間で絞れます。差を放置すると、広告費のうち実際にLPを見てもらえていない分が見えないまま、配信の判断を誤ります。

まず知る：リンクのクリックとLPビューは何が違うか

Meta広告のレポートには、クリックに関する数字がいくつも並びます。そのうち「リンクのクリック」と「ランディングページビュー」は、名前は似ていますが数えている瞬間が違います。

指標数えている瞬間数えるのに必要なもの
リンクのクリック広告の中のリンク（ボタン・画像・見出しなど）が押された瞬間Meta側だけで数えられる
ランディングページビュー押した人のブラウザで移動先のページが読み込まれ、ピクセルが反応した瞬間LPにMetaピクセルが入っていて、正しく動くこと

Metaは、ランディングページビューを導入した際の発表で、この指標を「広告のリンクのクリックの後にサイトへたどり着いた人」を測るものと説明し、読み込みの遅いページで離脱が起きることへの対策として位置づけています。（出典：Metrics Release: New Ways to Better Understand Interactions｜Meta Newsroom）つまり、リンクのクリックからLPビューまでの間で抜け落ちた人が、2つの数字の差になります。

また、海外の広告運用者の解説では、LPビューにはサイト側のピクセルが必要であること、リンクのクリックにはMetaの中のリンクへの移動や、押した直後の離脱も含まれ得ることが指摘されています。（出典：Landing Page View｜Jon Loomer Digital）

ポイント：差には「本当にLPを見てもらえていない差」と「見てもらえているのに数えられていない差」の2種類があります。前者は広告費のむだ、後者は計測の問題です。直し方がまったく違うので、まずどちらかを見分けることが大切です。

LPビューが少なくなるよくある原因6つ

当社が広告アカウントの点検で出会うことが多い原因は、次の6つです。

原因起きていること差の種類
1. LPの表示が遅いアプリ内ブラウザで読み込みに時間がかかり、表示される前に閉じられる。画像が重いLPや、表示前に別の処理を待つLPで起きやすい見てもらえていない
2. ピクセルがLPで動いていないLPにピクセルが入っていない、GTMの発火条件からLPが外れている、別ドメインのLPにだけ入っていない数えられていない
3. 同意バナー・ブロックで送られないCookieの同意を得るまでピクセルを止める設定や、広告ブロック・ブラウザの追跡防止でピクセルが送られない数えられていない
4. サイト以外の行き先が混ざっているInstagramのプロフィールへの移動、メッセージ、インスタントフォームなども「リンクのクリック」に数えられる場合があるそもそも比べる相手が違う
5. 誤タップ・興味の薄いクリックスクロール中の指が触れる、画面いっぱいの広告で押しやすい配置面に配信が寄っている見てもらえていない
6. URLの転送やパラメータで壊れる計測用の転送をはさむ、URLパラメータを付けるとエラーになる、LPを差し替えたあと古いURLが残っている見てもらえていない

原因4について補足すると、Metaが進めているアトリビューションの見直しでは、ウェブサイトや店舗のコンバージョンについて、クリック経由の成果に数えるのはリンクのクリックだけに絞られ、いいね・シェア・保存などの反応は「エンゲージスルー」として別に扱われると報じられています。（出典：Meta introduces click and engage-through attribution updates｜Search Engine Land）一方で、何が「リンクのクリック」に当たるかには、アプリストア・電話・メッセージ・リード獲得フォーム・Instagramのプロフィールへのリンクなど、ウェブサイト以外の行き先も含まれると解説されています。（出典：Click-Through Attribution Now Requires a Link Click｜Jon Loomer Digital）LPへの移動だけを比べたいときは、行き先がウェブサイトの広告だけに絞って数字を見てください。

差の出どころを突き止める確認手順

次の順で進めると、多くの場合15〜30分で原因の当たりがつきます。期間は直近7〜14日にそろえ、行き先がウェブサイトの広告セットだけを対象にしてください。

確認の順番

  • 手順1：広告マネージャの表に「リンクのクリック」と「ランディングページビュー」を並べ、広告セットごとに「LPビュー÷リンクのクリック」を出す。特定の広告セット・広告だけ低くないかを見る
  • 手順2：「内訳」で配置面別に分ける。特定の配置面（ストーリーズ、リール、Audience Networkなど）だけ割合が低いなら、原因5か原因1が濃厚
  • 手順3：同じく端末別（モバイル・パソコン）に分ける。モバイルだけ低いなら、原因1（表示の遅さ）を優先して疑う
  • 手順4：広告のプレビューから、実際にInstagramとFacebookのアプリ内でLPを開く。表示までの時間、途中で真っ白になる時間、エラーや転送の有無を見る（原因1・6）
  • 手順5：イベントマネージャのテストイベント機能やブラウザの拡張機能で、LPを開いたときにピクセルのPageViewが送られているかを確かめる。広告のURLにパラメータを付けた状態で試す（原因2・6）
  • 手順6：同意バナーがある場合は、「同意しない」を選んだときと選ぶ前に、ピクセルが送られるかどうかを確かめる（原因3）
  • 手順7：GA4でUTM付きの流入（参照元がfacebookやinstagram）のセッション数を同じ期間で見て、LPビューと大きく食い違っていないかを確かめる

手順7で、GA4のセッションはLPビューに近いのにリンクのクリックだけが大きい場合は、LPの手前で抜けている（原因1・5・6）可能性が高まります。逆に、GA4のセッションもLPビューも少ない場合は、表示の手前で離脱が起きているか、計測がどちらも止まっているかのどちらかです。GA4と広告の数字の違いそのものについては、GA4のセッション数・ユーザー数が合わない理由で整理しています。

注意：確認のために自分で広告を何度も押すと、その分の広告費がかかります。確認には広告のプレビューや、広告に設定しているURLを直接アプリ内で開く方法を使ってください。

原因別の直し方

原因1：表示が遅い

最初の画面を軽くする

  • ファーストビューの画像を圧縮し、最初に見える部分だけ先に読み込む
  • 表示前に読み込むタグや外部の部品を減らす
  • アプリ内ブラウザで実際の表示時間を測ってから直す

原因2・3：ピクセルが動かない

送られる条件を確かめる

  • LPを含む全ページでPageViewが送られるようにする
  • GTMの発火条件や、別ドメインのLPの設置漏れを点検する
  • 同意の設定が意図どおりかを確かめ、取りこぼしが出る前提で見る

原因4・5：比べ方と配信先

比べる対象と配置面をそろえる

  • 行き先がウェブサイトの広告だけで割合を見る
  • 割合が極端に低い配置面は、獲得単価も見たうえで外すか分ける
  • 押しやすさで選ばれる素材ではなく、内容が伝わる素材にする

原因6：転送・URL

URLを1本に整理する

  • 不要な転送をはずし、広告のURLをLPの最終URLにする
  • パラメータ付きでも正しく表示されるかを確かめる
  • LPを差し替えたら、すべての広告のURLを確認する

ピクセルだけに頼ると、同意やブラウザの制限による取りこぼしは避けられません。サーバー側からもイベントを送るコンバージョンAPIの考え方は、Meta広告のコンバージョンAPI｜導入手順と注意点で解説しています。LPの表示速度の直し方は、LPの表示速度とCVR｜Core Web Vitals改善の手順も参考にしてください。

なお、Metaの広告ポリシーでは、機能しないランディングページ（開けない、移動を妨げる、広告の内容と一致しないなど）に誘導する広告は認められていません。（出典：機能しないランディングページ｜Meta 透明性センター）原因6でLPがエラーになっている状態は、計測だけでなく審査の面でも早めに直すべきです。

どこまでの差なら様子を見てよいか

「LPビュー÷リンクのクリック」が何%なら正常という公式の基準はありません。配置面・端末・LPの重さ・同意バナーの有無で変わるためです。そのうえで、当社が実務で見ている目安は次のとおりです。

  • 割合が7〜8割以上で、毎週ほぼ同じなら、多くの場合は様子を見てよい状態です。施策の比較はこの割合が変わらない前提で行います
  • 割合が5〜6割台なら、配置面別・端末別に分けて、特に低いところがないかを確かめます。表示の遅さや誤タップが混ざっていることが多い水準です
  • 割合が5割を下回る、または急に下がったなら、ピクセルの停止・LPのエラー・転送の不具合を最優先で疑ってください

この目安は、行き先がウェブサイトの広告に絞った場合の数字です。インスタントフォームやメッセージへの広告が混ざっていると、割合は大きく下がって見えます。また、Metaのアトリビューションの見直しのように、媒体側の数え方が変わる時期には、変わる前と後の数字をそのまま比べないよう注意してください。

それでも差が縮まらないときの判断

手順をひと通り試しても差が縮まらない場合は、次の3つのどれに当たるかで動き方を決めます。

状態考えられること次の動き
LPビューは少ないが、問い合わせ・購入の数はLP側の記録と合う計測の取りこぼし（原因2・3）が中心で、成果は出ている差の割合を記録して傾向を見る。必要ならコンバージョンAPIを検討する
LPビューもGA4のセッションも少なく、獲得単価も悪いLPの手前で人が抜けている（原因1・5・6）LPの表示速度と配置面を優先して見直す。素材の作り方も見直す
原因が分からず、数字の食い違いが毎月大きく変わる複数の原因が重なっている、またはタグの管理が整理されていない計測の設計から点検し直す。広告・LP・計測をまとめて見られる人に相談する

リンクのクリックの数だけを見てクリック単価が安いと判断していると、実際にはLPを見てもらえていない広告に予算を寄せてしまうことがあります。広告の良し悪しは、LPビューあたりの単価や、最終的な問い合わせ・購入の単価で比べるのが安全です。

LnXの見解

リンクのクリックとLPビューの差は、広告のレポートの中では目立たない数字ですが、広告とLPと計測のつなぎ目で何が起きているかがいちばんよく表れる数字だと考えています。クリック単価が安く見える広告ほど、実はLPを見てもらえていなかった、という例は珍しくありません。

差の原因は、広告の配信設定・LPの作り・ピクセルの設置のどれか一つではなく、つなぎ目にあることが多いため、それぞれを別の担当者や別の会社が見ていると見落とされがちです。まずは本記事の手順で配置面・端末・ピクセルの3点を確かめ、差の割合を毎週記録するところから始めてみてください。

LnXの広告運用代行では、Meta広告の運用に加えて、広告の受け皿となるLPの制作・改善や、GA4・コンバージョン計測などの計測環境の構築まで自社で対応しています。広告・LP・計測のつなぎ目をまとめて点検したい場合は、お気軽にご相談ください。

よくある質問

Qリンクのクリックとランディングページビューは、どちらを見ればよいですか？

LPに来た人の数を知りたいときはランディングページビューを見てください。リンクのクリックは広告が押された数で、LPが表示される前に閉じた人や、サイト以外の行き先への移動も含まれることがあります。広告の良し悪しは、ランディングページビューあたりの単価や、問い合わせ・購入の単価で比べるのが安全です。

Qランディングページビューが0のままです。なぜですか？

LPにMetaピクセルが入っていないか、入っていても動いていない可能性が高いです。イベントマネージャのテストイベント機能などで、LPを開いたときにPageViewが送られているかを確かめてください。広告の行き先がインスタントフォームやメッセージの場合も、ランディングページビューは出ません。

Q差の割合は何%なら正常ですか？

公式の基準はありません。配置面・端末・LPの重さ・同意バナーの有無で変わるためです。当社が実務で見ている目安では、行き先がウェブサイトの広告で7〜8割以上が毎週ほぼ同じなら様子を見てよく、5割を下回る、または急に下がった場合はピクセルやLPの不具合を最優先で疑います。

Q特定の配置面だけ差が大きいときは、その配置面を外すべきですか？

すぐに外す前に、その配置面での問い合わせ・購入の単価も確かめてください。差が大きくても成果の単価が良ければ残す判断もあります。差が大きく、成果の単価も悪い場合は、外すか、広告セットを分けて予算を抑えることを検討してください。

QGA4のセッション数とランディングページビューも合いません。どちらが正しいですか？

どちらも完全に正しい数字ではなく、数え方が違います。GA4とMetaピクセルは、同意の扱いや計測の仕組みが異なるため、ある程度の差は出ます。差の割合が毎週ほぼ同じかどうかを見て、急に変わったときに設定の変更やタグの不具合を疑ってください。
