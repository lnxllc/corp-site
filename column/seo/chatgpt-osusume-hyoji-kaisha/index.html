結論：ChatGPTの「おすすめ会社」に載る条件

結論から言うと、ChatGPTの「おすすめ会社」に表示させるための特別な申請や裏技はありません。OpenAIは、ChatGPT検索に公開サイトが表示されるための条件として、OAI-SearchBotを許可することを挙げています（出典：Overview of OpenAI Crawlers｜OpenAI）。さらに、表示や掲載順位の保証はなく、掲載を申請する機能も示されていません（出典：Publishers and Developers FAQ｜OpenAI Help Center）。

では何もできないのかというと、そうではありません。当社は、「おすすめのWebマーケティング会社」を101通りの聞き方でChatGPTに質問して、どの会社が、どの記事を根拠に挙がるのかを実測しました。そこで見えたのは、AIが差し出す候補は16社に固定されており、その根拠の多くは「候補企業自身が書いた比較記事」だったという構造です。この記事では、公式の前提条件と当社の実測をもとに、おすすめ会社の候補に入るための施策と順番を整理します。

ChatGPTがおすすめ会社を出す仕組み

OpenAIの説明では、ChatGPTは第三者の検索プロバイダーやクローリングを通じてURLを取得し、質問との関連性が高い場合に結果へ表示します（出典：Publishers and Developers FAQ｜OpenAI Help Center）。クローラーには役割の違う3種類があり、検索結果への表示に関わるのはOAI-SearchBotです。GPTBotはモデルの学習用、ChatGPT-Userは利用者の操作で動くものとされています（出典：Overview of OpenAI Crawlers｜OpenAI）。

この前提を押さえると、自社に必要な対応は2段階に分かれます。1つ目は、OAI-SearchBotに読まれる状態にすること（robots.txtでブロックしない、OpenAIが公開するIPからのアクセスを許可する）。2つ目は、おすすめを聞かれたときに、自社が候補の材料として見つかる状態にすることです。1つ目は公式の仕様どおりに整えれば済みますが、勝負が分かれるのは2つ目です。仕様の詳細と7つの施策はChatGPT SEO対策｜表示・引用される7つの施策にまとめています。

おすすめに出る会社の4つの共通点

1,010件の集計から見えた共通点を、影響が大きいと当社が考える順に4つ整理します。これは当社の調査にもとづく見立てであり、ChatGPTの内部の選定基準が公開されているわけではありません。

  1. その領域の「比較記事」に名前が載っている：根拠の記事の86.1%が、候補企業側のオウンドメディアでした。自社サイトを整えるだけでなく、参照されている比較記事の側に名前があるかが影響します。
  2. サービス範囲が横断的に書かれている：常連7社は、広告運用とSEO・コンテンツなど複数領域をまたぐ記述が目立ちました。対応領域を列挙して書くほど、拾われる質問が増えます。
  3. 「誰向けか」の条件語が明示されている：「月20万円から」「BtoB・SaaS中心」「最低契約期間3か月」など、発注者が質問に入れる言葉で書かれた会社が、その条件の質問で拾われていました。
  4. 狭い領域なら、そこで上位に入れる：準常連の5社は全体では下位でも、得意カテゴリの質問ではTOP3に入っていました。総合1位ではなく、自社が本当に強い領域を狙うほうが現実的です。

ChatGPTのおすすめに表示させる施策7つ

施策1：OAI-SearchBotを許可する

robots.txtでOAI-SearchBotをブロックしていないか、OpenAIが公開するIPからのアクセスを遮断していないかを確認します。OpenAIによると、robots.txtの変更が反映されるまで約24時間かかります（出典：Overview of OpenAI Crawlers｜OpenAI）。

施策2：狙う質問を20〜30個作り、現在地を測る

「（自社の領域）で、中小企業向けのおすすめ会社は？」など、発注者が入力しそうな質問を作り、ChatGPTに入力して、自社名が出るか、何番目か、代わりに誰が出るかを記録します。

施策3：根拠として使われている比較記事を洗い出す

回答に表示される引用元のURLを控え、同じ記事が繰り返し使われていないかを見ます。当社の実測では、1,010件の根拠が6本の記事に収束していました。

施策4：その比較記事に載るための働きかけをする

運営者を確認し、掲載の可否や条件を問い合わせます。掲載時に渡す情報（対応領域・対応予算・得意業種・実績数値）は事前に整えておきます。掲載を依頼する場合は、費用や関係性を隠さない形で行ってください。

施策5：サービスページに、条件語を書き切る

対応領域を横断的に列挙し、対象企業の規模、対応予算レンジ、得意業種、契約形態を文章で明記します。「幅広く対応」のような抽象表現より、発注者が質問に入れる言葉のほうが拾われやすい、というのが当社の見立てです。

施策6：自社で、領域を正確に整理した比較・選び方の記事を持つ

自社が強い1領域に絞り、選び方と候補を整理します。自社を1位に置かず、領域全体を正確に整理した記事にします。実際に社名を並べる場合は、公式ページで確認した内容だけを書き、確認日を明記します。

施策7：同じ質問で定点観測し、流入を計測する

ChatGPTは、参照先へのリンクにutm_source=chatgpt.comを自動で付けると説明されており、GA4などで流入を確認できます（出典：Publishers and Developers FAQ｜OpenAI Help Center）。施策2と同じ質問リストで定期的に確認し、変化を記録します。

やってはいけない対策

  1. 「ChatGPTのおすすめに必ず載る」という提案を信じる：OpenAIは掲載や順位を保証しておらず、申請機能も示していません。
  2. 自社を1位に置いた露骨な比較記事を量産する：当社の見立てでは、領域全体が正確に整理されていない記事は、参照元として選ばれにくくなります。読者にとっても不利益です。
  3. 1回の回答だけで順位を判断する：回答は聞き方や時期で変わります。同じ質問リストで傾向を見てください。
  4. 出た順位を実力の順位と受け取る：当社の調査も、AIが既存の比較記事を要約した結果にすぎず、発注先の優劣を示すものではありません。
  5. 費用や関係性を伏せて、比較記事への掲載を依頼する：広告・PR関係がある場合は、その旨が分かる形にしてください。

自社でやるか、会社に頼むか

施策1〜3の「許可の確認」「現在地の測定」「根拠記事の洗い出し」は、社内でも始められます。工数が膨らむのは、サービスページの全面的な書き直しや、比較・整理記事の継続的な制作に入る段階です。ここが外注の分かれ目になります。

内製と外注の境目はAIO対策の内製と外注｜分岐点と体制の決め方で、会社に頼む場合の比較はAIO対策会社おすすめ6選｜費用・支援範囲を比較で、公式ページで確認できた情報にもとづいて整理しています。

LnXの見解

ChatGPTのおすすめ会社に載るには、特別な裏技より、「読まれる状態にする」「発注者の言葉で条件を書き切る」「領域を正確に整理した記事を持つ」「同じ質問で測り続ける」という地道な積み重ねが必要だと当社は考えています。当社自身も、今回の101問では一度も名前が挙がっておらず、同じ課題の当事者です。

当社は自社のオウンドメディアで、記事構成の設計から作成・入稿、SEOレポート、リライトまでを運用し、SEOと生成AI向けの要件を同じ制作フローの中で満たす方法をとってきました。その結果、生成AIインプレッションは約7倍、AIOスコアは91点（100点満点・Bランク）になっています。

この数値は自社メディアでの結果であり、他のサイトで同じ結果を保証するものではありません。また、ChatGPTのおすすめ会社に表示される順位を示す数値でもありません。自社がどの質問で出ているのか、まずは現状の無料診断からご相談ください。

よくある質問

Q ChatGPTのおすすめ会社に表示されるよう、OpenAIへ申請できますか？

OpenAIの公式FAQには、掲載を申請する機能は示されていません。公開サイトであればChatGPT検索に表示される可能性があり、OAI-SearchBotがアクセスできることが重要とされています。表示や順位の保証もありません。

Q OAI-SearchBot、GPTBot、ChatGPT-Userの違いは何ですか？

OpenAIの説明では、OAI-SearchBotはChatGPT検索の結果にサイトを表示するためのもの、GPTBotは生成AIモデルの学習用、ChatGPT-Userは利用者の操作で動くものです。検索結果への表示を狙うなら、OAI-SearchBotを許可する必要があります。

Q なぜ、おすすめの会社はいつも同じ顔ぶれになるのですか？

当社の実測では、101問を通じて名前が挙がった会社は16社だけで、上位7社が席の64.4%を占めました。根拠として記録された記事は6本で、うち4本が候補企業側のオウンドメディアでした。ChatGPTの内部の仕組みが公開されているわけではないため、当社の調査結果にもとづく見立てです。

Q 規模の小さい会社でも、おすすめに表示されますか？

当社の実測では、大手4社は「中小企業」「少額」などの条件が入った質問では外れており、知名度より質問の条件との一致が影響しているように見えました。得意な領域や対象を明記した会社は、その条件の質問で上位に入っていました。ただし、表示を保証できるものではありません。

Q 流入はどう計測しますか？

OpenAIは、ChatGPTが参照先へのリンクにutm_source=chatgpt.comを自動で付けると説明しています。GA4などでこの流入元を確認できます。あわせて、決まった質問リストで定期的に確認し、自社名が出たかを記録してください。

Q 自社でやるのと会社に頼むのはどちらがよいですか？

OAI-SearchBotの確認、質問リストでの現在地の測定、根拠記事の洗い出しは社内でも着手できます。サービスページの全面改修や、比較・整理記事の継続的な制作の段階で、会社への依頼を検討するのが現実的です。
