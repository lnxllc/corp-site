ヒートマップツールは、機能より「上限・保存期間・入力欄の扱い」で選ぶ

結論から言うと、ヒートマップツールの比較で最初に見るべきは、機能の数ではなく「無料枠の上限」「データの保存期間」「入力欄の扱い」の3つです。クリック・スクロール・熟読といった基本のヒートマップはどのツールにも揃っていて、そこで大きな差はつきません。差が出るのは、「先月のデータをいつまで見られるか」「月に何セッションまで取れるか」「フォームの入力内容が記録されないか」という運用に関わる部分です。

ヒートマップツールを並べた記事では、無料と有料の区分、料金、取れるヒートマップの種類、A/Bテストやアクセス解析との連携、サポートの有無といった観点が共通して取り上げられていました。この記事でも、それらは比較表に入れています。そのうえで、公式ページで確認できた範囲の「保存期間」「上限」「入力欄の扱い」を別の表に並べ直しました。導入してから「前月と比べたいのに先月分が消えていた」「フォームの中身が気になって使えなくなった」となるのを避けるための視点です。

なお、LP改善の中でヒートマップをどう読むかは、ヒートマップによるLP改善｜離脱点の見つけ方で扱っています。この記事は、その前段の「どのツールを入れるか」の比較です。

Microsoft Clarity

公式サイト：https://clarity.microsoft.com/　／　サービスページ：Microsoft Clarity ドキュメント

Clarityは、ヒートマップとセッション録画を無料で使えるツールです。公式FAQには「Clarity is a free service forever」と書かれ、トラフィックの制限も、1アカウントあたりのサイト数の制限もないと説明されています。トップページのタイトルも「Free Heatmaps & Session Recordings」です。クリックマップ、スクロールマップ、エリアマップといったヒートマップに加えて、実際の閲覧を再生できる録画が同じ画面で見られます。（出典：Clarity FAQ｜Microsoft Learn）

ただし、無料でも機能上の上限はあります。録画は1プロジェクトあたり1日10万セッションまで、ヒートマップは1つあたり10万ページビューまで、ライブセッションは最大100件まで閲覧できます。保存期間は、ヒートマップが最大9か月、録画は記録から30日（お気に入りの録画と無作為抽出のサンプルは最大9か月）です。

向いているケース：まず費用をかけずに、LPやフォームの動きを録画つきで確認したい。
注意点：録画の通常の保存は30日のため、後で見返したい録画はお気に入りに入れる運用が必要です。EEA・英国・スイスのユーザーを対象にする場合は、同意の取得が必要と公式に書かれています。日本語のサポート窓口の有無は、今回の確認では取れていません。

Contentsquare

公式サイト：https://contentsquare.com/　／　サービスページ：Pricing｜Contentsquare（英語）

hotjar.comの料金ページを開くと、contentsquare.com/pricing/に転送されました。そのページでは、Free・Growth・Pro・Enterpriseの4段階が示されています。Freeは0ドルで月20万セッションまで、保存は1か月、リプレイ・ヒートマップ・ファネルが使えます。Growthは月額39ドル（通常49ドルからの割引表示）で、セッション数は7千〜+24万の選択式、保存は13か月、ゾーン型ヒートマップとAIによるセッション要約が含まれます。ProとEnterpriseは要問い合わせです。（出典：Pricing｜Contentsquare）

表示は英語・ドル建てで、欧州顧客のGrowthプランはユーロ建てで請求されると書かれています。年払いにするとVAT前の金額から20%の割引とされていますが、年額の具体的な金額は記載がありません。Proの機能一覧には「最大6プロジェクト」とありますが、FAQには「3つ含まれ、さらに3つ購入可能」とあり、記述が一致していません。会社の所在地や日本向けの税表記は、取得したページに記載がありませんでした。

向いているケース：保存を13か月取れるプランで、前年同月との比較までやりたい。英語の画面で運用できる。
注意点：円建ての料金や日本の窓口は確認できていません。無料のFreeは保存が1か月と短いため、月次で振り返る運用には不足しがちです。

ミエルカヒートマップ

公式サイト：https://mieru-ca.com/　／　サービスページ：ミエルカヒートマップ

国内企業の株式会社Faber Companyが運営するヒートマップツールです（所在地は東京都港区虎ノ門と記載）。サイトのトップページのタイトルは「ミエルカSEO」となっており、SEOツールと同じ運営元のサービスとして提供されていることが読み取れます。ヒートマップは熟読・離脱・クリックの3種類で、無料アカウントを発行すると「無料の範囲内で期限なく」利用できると案内されています。

一方で、無料の範囲の具体的な上限、有料プランの金額、データの保存期間は、取得したページの本文では確認できませんでした。そのため、無料でどこまで使えるかは申し込み前に確認が必要です。

向いているケース：国内企業のツールで、期限なしの無料枠から試したい。熟読・離脱・クリックの3種類で足りる。
注意点：上限・保存期間・有料の金額が確認できていないため、無料の範囲を見極めてから本格導入するのが安全です。

SiTest

公式サイト：https://sitest.jp/　／　サービスページ：SiTest（トップページが製品ページ）

SiTestは、Webサイトの分析、A/Bテスト、動画接客をAIとノーコードで行うプラットフォームと説明されています。ヒートマップは、スクロール、マウスグラフィ、クリック、タップ、タッチアクションなどが挙げられています。画像やテキストをノーコードで編集してテストできるA/Bテストと、多変量テストも掲載されており、「見る」だけでなく「試す」ところまで同じツールで進められる点が特徴です。

料金は取得したページに記載がなく、無料プランの記載もありません。確認できたのは2週間の無料トライアルです。運営会社の表記は見つからず、ISMS認証の記載とフッターのリンクからグラッドキューブと読み取れる、という程度の確認にとどまります。所在地・税表記も記載を確認できませんでした。

向いているケース：ヒートマップで課題を見つけたあと、同じツールでA/Bテストまで進めたい。
注意点：料金が公開されていないため、他ツールと同じ条件で比較するには見積もりが必要です。トライアル期間は2週間のため、その間に確認したいページと指標を決めておく必要があります。

User Heat

公式サイト：https://userheat.com/　／　サービスページ：User Heat（トップページ）

User Heatのトップページには、無料版としてヒートマップ5種類、EFO機能、Google Search Consoleとの連携による検索ワードの可視化、テキストマイニング機能が挙げられています。より高度な分析をしたい企業向けには、有償版の「UserInsight」（ヒートマップ10種類以上、絞り込み25種類以上、SEO改善向け機能、パワーポイント形式のレポート自動作成など）が案内されています。運営はフッターの表記から、UserLocal, Inc.です。

無料版の月間の上限、保存期間、商用利用の可否は、トップページには明記がありません。関連する記述として「個人サイトで気軽に利用できます」とあるため、企業サイトで使う場合の条件は、利用規約などで確認したほうが安全です。

注意点：無料版の上限・保存期間・企業利用の条件が確認できていません。有償版の金額も、トップページには記載がありません。

LnX合同会社

入力欄とCookieの扱いを、導入前に確認する

ヒートマップや録画のツールは、ページ上の動きを記録します。そのため、フォームに入力された内容や、画面に表示された個人情報が記録されないかは、導入前に必ず確認してください。

Clarityの公式ドキュメントでは、マスキングのモードが3つ示されています。既定はBalancedで、数字とメールアドレスを機微な内容として分類してマスクします。Strictは全内容をマスクし、Relaxedは内容をマスクしません。ただし、入力欄の内容はすべてのモードでマスクされ、カスタマイズできません。ドロップダウンも同様です。特定の要素をマスクしたい場合は、CSSセレクタか、HTMLの属性（data-clarity-mask）で指定できます。マスクの設定を変更しても、反映されるのは新しい録画からで、反映までに最大1時間かかり、過去の録画には遡って適用できません。（出典：Clarity masking｜Microsoft Learn）

Cookieについては、Clarityの公式FAQが、利用するCookieをユーザーに通知する必要があるかという問いに「Yes」と答えています。EEA・英国・スイスのユーザーに対しては、Cookieを置く前に明示的な同意が必要とされ、同意がない場合は、ファネル追跡やセッション録画などの機能に影響が出ると書かれています。（出典：Clarity FAQ｜Microsoft Learn）

他の4ツールについては、今回取得したページにマスキングの仕様が見つかりませんでした。導入前に、「入力欄は記録されるか」「マスクは誰がどこで設定するか」を各社に確認してください。同意取得の考え方は同意モードv2は日本企業に必要か｜判断基準とGTM設定で整理しています。個人情報保護法などの個別の判断は、弁護士等の専門家にご確認ください。

入れた後に続けるための、見る頻度と見る順番

ヒートマップは、入れただけでは改善につながりません。当社の目安では、週1回30分、見る人と曜日を決めるところまでが導入の作業です。見る順番も、次のように決めておくと迷いません。

順番見るものそこから立てる仮説の例
1スクロールの到達（どこで読まれなくなるか）訴求の本題がその位置より下にある
2クリックの集まり（リンクでない箇所を含む）押せると思われている箇所がある／ボタンが目立たない
3フォーム周辺の動き（録画があれば入力の止まる位置）項目が多い／入力しにくい欄がある

1回に直すのは1点だけにして、2〜4週間はそのまま動かさず、GA4のコンバージョン率で結果を確認します。複数の箇所を同時に直すと、どれが効いたのか分からなくなります。具体的な見方はヒートマップによるLP改善｜離脱点の見つけ方、LP全体の優先順位はLPのCVRを改善する方法｜広告成果を上げるチェックポイント完全版で扱っています。

ヒートマップツール導入前の確認7項目

  • 無料枠の上限は、何の単位（セッション・ページビュー・ページ数）で決まっているか。超えたらどうなるか
  • ヒートマップと録画の保存期間は何か月か。月次の振り返りに足りるか
  • 入力欄とドロップダウンは記録されないか。マスクの設定は誰ができるか
  • Cookieの告知とプライバシーポリシーに、ツール名と目的を追記する準備ができているか
  • 計測の対象ページを2〜3ページに絞ったか。見る人と曜日は決まっているか
  • GA4と同じページ・同じ期間で、数とヒートマップを照らし合わせられるか
  • やめるときにデータを書き出せるか。有料の場合、最低契約期間と解約の条件は何か

LnXの見解

ヒートマップツールは、どれを選ぶかより、入れた後に「誰が、いつ、何を直すか」を決めておくことのほうが成果に効くと考えています。無料のツールでも、毎週見て毎回1点直す会社のほうが、高機能なツールを入れて放置する会社より、LPは良くなります。

当社の広告運用代行のページでは、簡易LP制作費10万円〜、運用手数料20%（出稿額50万円未満は月10万円）、Meta広告のみの新規契約向けスタートプラン月額33,000円（税込）〜、最低契約6か月という条件を公開しています。この条件は、広告・LP・計測をまとめて任せたい方に向いていますが、ヒートマップの分析だけを単独で依頼したい方には、最適とは限りません。その場合は、まず無料ツールで数週間試し、足りない点を具体的にしてからご相談ください。

他社の提案書や見積もりを並べた状態でのご相談も歓迎です。ツールの比較だけでなく、LPと広告をどの順番で直すかまで、一緒に整理します。

よくある質問

Q ヒートマップツールは無料で足りますか？

公式ページで確認できた範囲では、Microsoft Clarityは無料のままトラフィック制限なしと明記されており、1プロジェクトあたり1日10万セッションまで録画、ヒートマップは1つあたり10万ページビューまでという機能上の上限があります。LP数枚から中規模のサイトであれば足りることが多い一方、録画の通常の保存が30日である点は運用で補う必要があります。前年同月との比較など長期の保存が必要になった段階で、有料プランを検討してください。

Q 無料ツールのデータは、どのくらいの期間見られますか？

ツールによって異なります。Microsoft Clarityはヒートマップを最大9か月、セッション録画は記録から30日（お気に入りに入れた録画と無作為抽出のサンプルは最大9か月）と記載されています。Contentsquareの無料プランは1か月、月額39ドル〜のGrowthプランは13か月です。ミエルカヒートマップ・SiTest・User Heatは、今回取得した公式ページに保存期間の記載を確認できませんでした。

Q 入力フォームに打ち込まれた内容も記録されてしまいますか？

Microsoft Clarityでは、入力欄の内容はどのマスキングモードでもマスクされ、カスタマイズできないと公式に記載されています。ドロップダウンも同様です。他のツールのマスキング仕様は今回取得したページで確認できていないため、導入前に各社へ確認してください。個人情報の取り扱いに関する個別の判断は、弁護士等の専門家にご確認ください。

Q ヒートマップとGA4はどう使い分けますか？

GA4は「どのページで何人が離脱し、何件コンバージョンしたか」という数を見るツールで、ヒートマップは「そのページのどこが読まれ、どこでクリックされているか」というページ内の動きを見るツールです。数でページを絞り込み、ヒートマップで原因の仮説を立て、修正後にGA4で数が変わったかを確認する、という順番で使うと役割が重なりません。

Q どのページから入れるのがよいですか？

当社の考え方では、広告やSNSからの流入が最も多い着地ページ（LP）と、問い合わせフォームの直前のページの2つから始めます。全ページに入れても、見る時間が足りず放置されやすいためです。最初は2〜3ページに絞り、週1回の確認が続いたら範囲を広げてください。

Q 複数のヒートマップツールを併用してもよいですか？

技術的には可能ですが、Cookieや計測タグが増えるため、プライバシーポリシーやCookieの告知に記載するツールも増えます。また、同じページで結果が食い違うと判断に迷うため、当社では1つに絞って一定期間使い込み、足りない機能が明確になってから追加することをおすすめしています。
