Copilotに社内ファイルが
見えてしまう原因と対処

2026年11月26日 AI活用Copilot情報管理

この記事でわかること

  • Copilotに見えてはいけない社内ファイルが出てくる本当の理由
  • 見えてしまう状態が生まれる5つの経路と見つけ方
  • 一般の社員の立場で確かめる手順と、見つけたときの初動
  • 共有設定・置き場所・管理ツールで再発させない直し方

結論：Copilotに見えてはいけない社内ファイルが出てくるのは、Copilotの不具合ではありません。Copilotは既存の権限の範囲で答えるため、出てきたファイルはもともとその社員が開ける状態だったファイルです。原因の多くは、組織全体へのリンク、全社のグループへの共有、公開設定のチームなど、広く共有したまま忘れられた設定です。まず一般の社員と同じ権限のアカウントでCopilotに試しに聞き、出てきたファイルの共有を絞ってください。Copilotを止めても、ファイルを開ける状態は残ります。

Copilotが見せているのは「もともと見られる」ファイル

Microsoft 365 Copilotを入れたら、社員の質問に、給与の一覧や人事評価、取引先との契約書が出てきた。こうした相談は、Copilotを導入した会社で珍しくありません。まず押さえておきたいのは、Copilotが勝手に権限を広げているわけではないということです。

Microsoftの説明では、CopilotとエージェントはMicrosoft Graphからデータを取得し、既存のアクセス許可・共有設定・ポリシーを尊重するとされています。（出典：SharePoint 高度な管理を使用して Microsoft Copilot とエージェントに備える｜Microsoft Learn）言いかえると、Copilotに出てきたファイルは、その社員がもともと開ける状態だったファイルです。

これまでは、開ける状態でも「どこにあるか知らない」「探そうとしない」ために、問題が表に出ませんでした。Copilotは社内のファイルを横断して答えを探すため、何年も前に広く共有したまま忘れられていたファイルまで、質問ひとつで目の前に出てきます。つまり、起きているのはCopilotの不具合ではなく、共有のしかたの古い問題が見えるようになったということです。

Copilotを止めるだけでは解決しない：Copilotの利用を止めても、そのファイルを社員が開ける状態は変わりません。見えてはいけないファイルが見つかったら、Copilotではなくファイルの共有設定を直す必要があります。

見えてはいけないファイルが生まれる5つの経路

中小企業で「見えてしまう」状態が生まれる経路は、おおむね次の5つです。Microsoftも、組織全体へのリンクや「すべてのユーザー」への共有など、範囲の広い共有を注意すべきものとして挙げています。（出典：SharePoint 高度な管理を使用して Microsoft Copilot とエージェントに備える｜Microsoft Learn）

経路よくある場面見つけ方の手がかり
1. 組織内の全員が使えるリンク会議の前に「とりあえず社内の人は誰でも見られるリンク」で共有し、そのまま残っているファイルの「アクセス許可の管理」に組織全体のリンクがある
2. 「すべてのユーザー」への共有サイトやフォルダの権限に、社員全員を表すグループがまとめて入っているサイトのメンバーや権限の一覧に、全社のグループが入っている
3. 公開（パブリック）設定のチームTeamsのチームを公開で作り、そのチームのファイルに人事や経理の資料を置いたチームの設定が「パブリック」になっている
4. 全社共有フォルダへの置きっぱなし「共有」「総務」などのフォルダに、給与や評価のファイルを一時的に置いた全社向けのサイトに、人名や金額が入ったファイル名がある
5. 異動・退職の後に残った権限部署を移った人や、外部の協力者の権限が外されていないメンバー一覧に、今の担当ではない人がいる

Microsoftの資料では、SharePointの共有設定は、既定では最も緩い選択肢になっているとも説明されています。（出典：SharePoint 高度な管理を使用して Microsoft Copilot とエージェントに備える｜Microsoft Learn）導入時に共有の設定を見直していない会社ほど、この5つが積み重なっています。

自分で確かめる手順

専用の管理ツールが無くても、次の手順で「どこが見えてしまっているか」の当たりをつけられます。管理者と、一般の社員と同じ権限のテスト用アカウントの2つを用意して進めます。

  1. 一般の社員の立場でCopilotに聞いてみる：テスト用アカウントでCopilotを開き、「給与」「賞与」「人事評価」「退職」「見積」「契約書」「パスワード」など、見えてはいけない情報につながる言葉で質問します。出てきたファイルを一覧にします。
  2. 出てきたファイルの共有のしかたを見る：一覧のファイルを開き、「アクセス許可の管理」で、どんなリンクで、誰に共有されているかを確かめます。組織全体のリンクや、全社のグループが入っていれば、経路1か2です。
  3. ファイルが置かれている場所を見る：そのファイルが、どのサイト・どのチームにあるかを確かめます。公開設定のチームや全社向けのサイトにあるなら、経路3か4です。
  4. 同じ場所のほかのファイルも見る：問題のファイルが見つかった場所には、似た性質のファイルがまとまっていることが多いです。同じフォルダの中身もあわせて確かめます。
  5. メンバーの一覧を見る：機密の資料を置いているサイトやチームのメンバーに、異動した人や外部の人が残っていないかを確かめます。

手順1の言葉の一覧は、業種によって変わります。医療や士業なら患者・顧客の名前、製造業なら原価や図面の番号など、自社で「出てきたら困る言葉」を5〜10個決めて試すと、取りこぼしが減ります。

見つけたときの初動

見えてはいけないファイルが見つかったら、慌ててファイルを消すのではなく、次の順番で対応します。

  1. 状況を記録する：どのファイルが、どの場所に、どんなリンク・権限で共有されていたかを、画面の写しと一緒に残します。後で影響の範囲を考えるときに必要になります。
  2. 共有を絞る：組織全体のリンクを削除し、全社のグループを権限から外して、本当に必要な人だけが開ける状態にします。ファイルを消すより先に、共有を絞るほうが安全です。
  3. 置き場所を移す：給与や評価など、限られた人しか見てはいけない資料は、メンバーを絞った専用のサイトやチームに移します。
  4. 影響の範囲を考える：いつから共有されていたか、誰が開ける状態だったかを整理し、社内で報告すべき相手を決めます。

見つかったファイルに個人情報が含まれている場合、社内でどこまで報告・対応すべきか、外部への報告が必要になるかは、情報の中身や状況によって変わります。個別の判断は弁護士等の専門家に確認してください。

再発させない直し方

1. 共有の「上限」と既定を決め直す

SharePointとOneDriveでは、組織全体で許す外部共有の範囲を4段階から選び、サイトごとの設定はその範囲を超えられない仕組みになっています。誰でも開けるリンクには有効期限を付けたり、既定の権限を閲覧のみにしたりすることもできます。（出典：Set the boundary: SharePoint and OneDrive sharing settings｜Microsoft Learn）まずは、自社で「どこまでの共有を許すか」を決め、管理センターの設定をそれに合わせます。

ただし、閲覧のみのリンクにしても、そのファイルがCopilotの答えに出てくること自体は防げない点に注意が必要です。（出典：Set the boundary: SharePoint and OneDrive sharing settings｜Microsoft Learn）見られて困るファイルは、閲覧のみにするのではなく、そもそも共有の範囲から外します。

2. 機密の資料は「置き場所」で分ける

人事・経理・役員会の資料など、限られた人しか見てはいけない資料は、メンバーを絞ったプライベートのサイトやチームにまとめます。ファイル1つ1つの権限で管理するより、置き場所で分けるほうが、異動や退職のときにも崩れにくくなります。チームを新しく作るときは、プライベートで作ることを社内のルールにします。

3. 管理ツールで、Copilotの検索対象から外す

Microsoftは、サイトへのアクセスを特定のグループに限る機能や、権限を変えずにCopilotや組織全体の検索の対象からサイトを外す「制限付きコンテンツ検出」といった機能を案内しています。あわせて、範囲の広い共有を洗い出すレポートで、定期的に状態を確かめることもすすめられています。（出典：SharePoint 高度な管理を使用して Microsoft Copilot とエージェントに備える｜Microsoft Learn）これらの機能を含むSharePoint Advanced Managementは、Microsoft Copilotのライセンスに含まれると説明されています。（出典：Microsoft Copilot のセキュリティ保護とガバナンス: 基本的な展開ガイダンス｜Microsoft Learn）

ただ、検索の対象から外す方法は、あくまで「Copilotに出さない」ための対策です。社員がそのファイルを開ける状態は残るため、1と2の見直しと組み合わせて使います。

4. 共有のルールを社内に示す

設定を直しても、共有のしかたが変わらなければ、同じ状態にまた戻ります。「組織全体のリンクは使わない」「人事・経理の資料は専用のチームに置く」「プロジェクトが終わったらメンバーを外す」など、短いルールを決めて社内に示します。生成AIの社内ルール全体の作り方は、生成AIの社内利用ルールの作り方｜6章構成で整理しています。

それでも解決しないときの判断の目安

上の手順を進めても、見えてはいけないファイルが次々に見つかる場合は、次の目安で判断します。

  • サイトやチームの数が把握できない：誰が作ったか分からないサイトやチームが多く、1つずつ確かめるのが現実的でないなら、管理ツールのレポートで全体を洗い出すことを優先します。
  • 機密の資料の量が多い：人事や経理の資料が全社のあちこちに散らばっているなら、Copilotの利用範囲をいったん一部の部署に絞り、置き場所の整理が終わってから広げる進め方も検討に値します。
  • 社内に管理者がいない：Microsoft 365の管理を担当者1人が片手間でしている場合は、最初の棚卸しだけでも外部の支援を使うと、見落としと手戻りを減らせます。

生成AIの情報漏洩の経路は、Copilotの共有の問題だけではありません。社員が個人のAIサービスを使う「シャドーAI」なども含めた全体像は、生成AIの情報漏洩リスクはどこにある？シャドーAI・学習利用設定・取引先との合意で整理しています。

LnXの見解

Copilotで見えてはいけない社内ファイルが出てきたとき、多くの会社が最初に考えるのは「Copilotを止めるかどうか」です。しかし当社は、これを社内の情報の置き方を見直す良い機会だと考えています。Copilotが出したファイルは、もともと誰でも開ける状態だったファイルであり、Copilotが無くても、いつか誰かが開いていた可能性があります。

だからこそ、Copilotを止めることより、一般の社員の立場で試しに聞いてみて、出てきたものから順に共有を絞ることをおすすめします。全部を一度に整えようとせず、「出てきたら困る言葉」を決めて、当てはまるファイルから直すだけでも、危ない状態の多くは解消できます。

LnXは、中小企業の生成AIの導入と、社内で安心して使うためのルールづくりを支援しています。「Copilotを入れたいが、社内のファイルが整理できていない」という段階からご相談いただけます。

※Microsoft 365やCopilotの機能・ライセンス・管理画面の名称は更新されます。設定を変える前に、最新の公式情報も確認してください。

よくある質問

QCopilotは、権限の無いファイルまで勝手に読んでいるのですか？

いいえ。Microsoftの説明では、Copilotは既存のアクセス許可や共有設定を尊重して情報を取得するとされています。Copilotに出てきたファイルは、その社員がもともと開ける状態だったファイルです。直すべきなのは、Copilotではなくファイルの共有のしかたです。

QCopilotの利用を止めれば、問題は解決しますか？

解決しません。Copilotを止めても、そのファイルを社員が開ける状態は残ります。見えてはいけないファイルが見つかったら、組織全体のリンクを削除したり、置き場所を移したりして、共有の範囲そのものを絞ってください。

Q閲覧のみのリンクにすれば、Copilotに出なくなりますか？

出なくなるわけではありません。閲覧のみのリンクは編集を防ぐものです。Microsoftの資料でも、閲覧のみにしても見つけられること自体は防げないと説明されています。見られて困るファイルは、共有の範囲から外してください。

Q専用の管理ツールが無い小さな会社でも確かめられますか？

確かめられます。一般の社員と同じ権限のテスト用アカウントでCopilotに「給与」「人事評価」「契約書」などの言葉で質問し、出てきたファイルの共有のしかたを1つずつ確かめる方法なら、追加のツールが無くても始められます。

Q見つかったファイルに個人情報が入っていた場合は、どうすればいいですか？

まず状況を記録し、共有を絞ってから、いつから誰が開ける状態だったかを整理してください。社内外への報告が必要かどうかは、情報の中身や状況によって変わるため、個別の判断は弁護士等の専門家に確認してください。
